# gti-1c-mcp

MCP-сервер для работы с **1С:БИТ.СТРОИТЕЛЬСТВО (БИТ.ФИНАНС)**: инструкции пользователя, маршруты согласования и доступ к живой базе 1С.

Подключается к любому MCP-клиенту (Claude Desktop, Cursor, OpenCode, ChatGPT Desktop) и позволяет спрашивать про 1С обычным языком.

---

## Возможности

- **75 инструкций пользователя** — семантический (TF-IDF) и точный поиск
- **Маршруты согласования** по 28 организациям — подбор цепочки, сравнение, блок-схемы Mermaid
- **Живая база 1С** — метаданные, документы, визы, права пользователей, произвольные запросы на чтение
- **Самодиагностика прав** — «каких прав мне не хватает для работы с документом» и какой профиль запросить

Всего 18 инструментов.

---

## Безопасность

Сервер ходит в продуктивную базу, поэтому доступ ограничен на нескольких уровнях:

- **Персональные токены.** У каждого пользователя свой токен с ролью. Хранится только SHA-256 хеш.
- **Делегирование identity.** Запрос к 1С идёт под доменной учёткой владельца токена — работают права и RLS этого сотрудника.
- **Роли.** `user` — только инструкции и проверка собственных прав на документ; `analyst` — всё, кроме произвольного запроса; `admin` — плюс `execute_1c_query`. Инструменты не своей роли не видны в списке.
- **Защита ПДн.** ФИО, логины и контактные данные заблокированы внутри расширения 1С. Сотрудники идентифицируются по `ИдентификаторПользователяИБ`.
- **Аудит.** Каждый вызов пишется JSON-строкой с префиксом `AUDIT`: кто, что, когда, с каким результатом.
- **Строгий TLS.** Проверка сертификата включена, доверие к внутреннему УЦ — через CA-бандл.

Подробнее — в [AGENTS.md](AGENTS.md).

## Установка

Требуется Node.js 18+.

```bash
git clone https://gitlab.ide-spb.com/saraninrg/gti-1c-mcp.git
cd gti-1c-mcp
npm install

cp .env.example .env          # Windows: copy .env.example .env
node tools/token.mjs genkey   # → вписать MCP_SECRET_KEY в .env
```

В `.env` заполнить подключение к 1С:

```ini
ONEC_URL=https://server/base
ONEC_USERNAME=Логин
ONEC_PASSWORD=Пароль
```

Выдать себе токен и запустить:

```bash
node --env-file=.env tools/token.mjs issue --login "HG\ВашЛогин" --role admin
npm start
```

Проверка: `curl http://localhost:3031/health`

## Управление доступом

Роли: `user` (по умолчанию) — инструкции и проверка своих прав; `analyst` — данные живой базы и маршруты; `admin` — плюс произвольный запрос.

```bash
# выдать токен обычному пользователю (пароль спросит скрытым вводом)
node --env-file=.env tools/token.mjs issue --login "HG\ИвановИИ" --comment "Иванов, бухгалтерия"

# аналитику
node --env-file=.env tools/token.mjs issue --login "HG\СидороваАА" --role analyst

# администратору, на 90 дней
node --env-file=.env tools/token.mjs issue --login "HG\ПетровПП" --role admin --days 90

node --env-file=.env tools/token.mjs list                    # состояние всех токенов
node --env-file=.env tools/token.mjs revoke --id tok_a1b2c3  # отозвать при увольнении
```

Токен показывается один раз — сохраните его сразу.

## Примеры

**Инструкция**
```
search_instructions(query="создать путевой лист")  → ИП-301
get_instruction(id="ИП-301")
```

**Маршрут согласования**
```
suggest_route(org="ГТИ", doc_type="ЦС-004", amount=6000000)
→ Инициатор → Финансовый контроль БЕ [ГТИ] → Генеральный директор БЕ [ГТИ]
```

**Каких прав не хватает (любой пользователь, про себя)**
```
check_document_access(document_type="бит_ЗаявкаНаРасходованиеСредств")
→ Проведение: нет → запросить профиль «БИТ.Казначей»
```

**Какие визы может ставить сотрудник (analyst)**
```
get_visa_routes(mode="rights", user_uid="490933bc-...")
→ визы с пометкой granted_via: direct | group
```

**Запрос к базе (admin)**
```
execute_1c_query(
  query_text="ВЫБРАТЬ Наименование, ИНН ИЗ Справочник.Контрагенты ГДЕ Город = &Город",
  params={"Город": "Чита"}, limit=50)
```

## Расширение 1С

Для работы с живой базой нужно расширение `build/MCP_Сервер.cfe`:

1. Конфигуратор → Расширения конфигурации → добавить `.cfe`
2. Опубликовать базу через Apache/IIS
3. Перезапустить сеансы

> Регистр имени базы в URL должен совпадать с именем публикации.

После правки BSL расширение пересобирается: `python -m v8unpack -B cfe_src build/MCP_Сервер.cfe`, затем «Обновить из файла» в Конфигураторе.

## Проверка

```bash
node tools/check_all.mjs <user-токен> <analyst-токен> <admin-токен>
```

Проверяет разграничение трёх ролей, блокировку ПДн, read-only, отбор прав виз по сотруднику, самодиагностику прав на документ и работоспособность инструментов.
