# ИП-401. Инструкция пользователя. Порядок формирования перемещения МПЗ между складами в 1С.БИТ

> Источник: `ИП-401. Инструкция пользователя. Порядок формирования перемещения МПЗ между складами в 1С.БИТ.docx`  
> Код инструкции: `ИП-401`  
> Тип: .DOCX

---

## Открытие документа перемещение МПЗ между складами
- Для создания Перемещения МПЗ между складами пользователь должен в 1С.БИТ перейти в блок «Снабжение и склад», далее в разделе «Склад» выбрать «Перемещение МПЗ между складами» (Рисунок А1).
- Рисунок А1. Открытие журнала «Перемещение МПЗ между складами»
- Далее в открывшейся форме на командной панели нажать на кнопку [Создать] отмеченной на Рисунке А2.
- Рисунок А2. Форма списка документа «Перемещение МПЗ между складами».
- ! Форма документа «Перемещение МПЗ между складами» имеет несколько видов операций такие как «Перемещение между складами», «Заправочная ведомость», «Слив топлива».
- Рассмотрим заполнение полей формы с видом операции «Перемещение между складами».
## Заполнение документа «Перемещение МПЗ между складами»
- В открывшейся форме требуется заполнить поля шапки документа (Рисунок А3):
- Рисунок А3. Заполнение «шапки» документа.
- Номер – присваивается программой автоматически.
- Дата – указать дату фактического перемещения со склада.
- Организация – выбрать организацию.
- Склад отправитель – склад, с которого производится перемещение материалов.
- Склад получатель – склад, на который производится перемещение материалов.
- Вид операции – указать «Перемещение между складами»
- Проект – заполнить проект.
- Бух. учет – устанавливать всегда, для отражения операции по бухгалтерскому учету.
- Заполнить табличную часть «МПЗ», нажав на кнопку «Подбор МПЗ» (Рисунок А3).
Рисунок А3. Подбор МПЗ в табличную часть.
- По кнопке «Подбор МПЗ» пользователь попадает в обработку «Подбор номенклатуры», которая разделена на четыре области:
- Первая рабочая область – отборы по резервам. Раздел доступен если установлен флаг [С учетом резервов]. Отбор позволяет быстро отобрать МПЗ если известен номер заявки на МПЗ. Выбрать заявку на МПЗ можно из формы подбора. При выборе заявок на МПЗ, в табличной части списка номенклатуры останется только та номенклатура, которая указана в выбранных заявках на МПЗ.
- Вторая рабочая область – группы номенклатуры. Если установлен флаг [Показывать по иерархии], то в левой рабочей области отображается номенклатура из выбранной справа группы. Если флаг [Показывать по иерархии] не установлен - то в левой рабочей области отобразятся все элементы справочника «Номенклатура» с учетом выбранной кнопки отображать остатки;
- Третья рабочая область – элементы справочника «Номенклатура», порядок отображения данных в описываемой области определяется кнопками отображать остатки:
- отображать остатки [Все] – при выборе, отобразится вся номенклатура с остатками и без.
- отображать остатки [В наличии] – позиции, которые есть в наличии, но зарезервированы под заявку на МПЗ.
- отображать остатки [Доступно] – позиции в наличии + незарезервированные МПЗ (в свободном остатке).
- Поле [На дату (конец дня)] - если переключатель установлен в положение «В наличии» или «Доступно», то при установке даты в реквизите «На дату (конец дня)» отбор остатков будет произведен с учетом установленных условий по дате на конец дня. При установке флага [Дата из формы владельца] реквизит «На дату (конец дня)» устанавливается автоматически и соответствует дате документа, из которого открыта форма подбора номенклатуры.
- При установке флага [Отображать архивную номенклатуру], в списке появится номенклатура, которая помещена в архив и не используется в программе.
- Четвертая область обработки – элементы подобранной номенклатуры, отобранные пользователем для переноса в документ (может быть скрыта по кнопке [Скрыть подобранные]). Если область не отображается, необходимо нажать кнопку [Отображать подобранные].
- Рисунок А4. Форма подбора номенклатуры.
- Данные подберутся в табличную часть «МПЗ» (Рисунок А5).
Рисунок А5. Подобранные ТМЦ в табличную часть.
- Проверить документ и нажать на кнопку [Провести] (Рисунок А6). Документ сохранится.
- Рисунок А6. Проведение документа.
- На основании текущего документа необходимо создать документ по бухгалтерскому учёту, для этого нажмите на кнопку с зеленой галочкой [УУ->БУ Создать] (Рисунок А7), по БУ создастся документ «Перемещение товаров, материалов». Выйдет сообщение, о том, что документ создан в бухгалтерском документе в сообщении будет указан номер документ и его дата.
- Рисунок А7. Кнопка создания документа по БУ.
- Для перехода к документу «Перемещение товаров, материалов» нажимаем на кнопку с голубой стрелкой (Рисунок А8). Откроется документ, созданный по БУ на предыдущем шаге. Далее требуется выполнить обработку бухгалтерского документа «Перемещение товаров, материалов» по инструкции «ИП-450 Инструкция пользователя. Порядок формирования документа «Перемещение товаров, материалов»».
- Рисунок А8. Переход к документу БУ перемещение товаров, материалов.
