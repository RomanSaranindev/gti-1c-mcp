# 1. ОБЩИЕ ПОЛОЖЕНИЯ

**1.1** В данной инструкции используются следующие понятия:

- **Визирование** – процесс согласования и утверждения документов ответственными лицами Компании в 1С.БИТ.
- **Виза** – реквизит, имеющий название и привязку к конкретному ответственному лицу (далее – рецензент), либо группе лиц в Компании.
- **Последовательность визирования** – порядок согласования, который может быть последовательным или параллельным.
- **Цепочка согласования** - комбинация из Виз, последовательности визирования и условий включения Визы.
- Каждый документ, требующий согласования и утверждения в 1С.БИТ, имеет соответствующую **Цепочку согласования.**
- Цепочки согласования по всем организациям размещены в папке **X:\GTI\Инструкции 1С.БИТ\000. ЦЕПОЧКИ СОГЛАСОВАНИЯ.**

# 2. ВИЗИРОВАНИЕ ДОКУМЕНТОВ

**2.1** Рецензенту для согласования документов в 1С.БИТ необходимо открыть Рабочее место визирования: раздел «Казначейство», подраздел «Сервис» (Рисунок 1).

**2.2** Для удобства использования Рабочее место визирования необходимо перенести на панель избранного.

**2.3** При открытии Рабочего места визирования выведется список документов, требующих визирования.

**2.4** При необходимости можно открыть любой документ из списка двойным нажатием на соответствующую строку.

**2.5** Установка соответствующей визы возможна **по группе документов**:
- выделить из списка необходимые документы, нажав на «звездочки» слева от названия документа;
- выбрать решение (Отклонено\Согласовано);
- при необходимости указать комментарий;
- нажать «**Установить решение**».

**2.6** Для **индивидуального согласования документа** необходимо:
- перейти в документ из списка;
- нажать раздел «Согласование»;
- на вкладке «Визирование» установить своё решение.
