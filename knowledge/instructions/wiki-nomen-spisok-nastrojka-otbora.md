# Список номенклатуры в 1СБИТ. Настройка отбора

Код инструкции: ``
Источник: `wiki.hg.loc/spaces/1C`
Раздел: Нормализованный справочник номенклатуры

---

Для Справочника номенклатуры в программе 1СБИТ разработаны следующие варианты отборов с помощью переключателя «Отбор по типу»:

- **Товарные** — нормализованные записи товарных наименований
- **Эталонные** — нормализованные записи эталонных наименований
- **Ненормализованные** — оставшиеся ненормализованные записи
- **Все (Development)** — все имеющиеся номенклатурные записи (как нормализованные, так и ненормализованные)
- **Highland Gold** — номенклатурные записи справочника Highland Gold для сотрудников, работающих с организациями Озёрное и Култуминское

Для выбора типа отбора нужно нажать на необходимое поле переключателя. Выбранный вариант отбора выделяется зеленым цветом.

При закрытии Справочника программа запоминает установленный пользователем вариант отбора.

**Варианты отборов:**

Все имеющиеся номенклатурные записи — выбрано поле **Все (Development)**:
- Записи нормализованного справочника номенклатуры
- Записи номенклатуры, созданные ранее мая 2025 и не прошедшие нормализацию

Оставшиеся ненормализованные записи — выбран отбор по полю **Ненормализованные**.

Нормализованные записи эталонных наименований — выбрано поле **Эталонные**.

Нормализованные записи товарных наименований — поле **Товарные**.
