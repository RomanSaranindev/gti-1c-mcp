Установка контрольных значений
Для установки значений, в соответствии с которыми будут контролироваться суммы расходов по заявкам на расходование денежных средств, графики договоров и (или) суммы оборотов по отдельным бюджетам, в конфигурации предназначен документ «Установка контрольных значений».
Документ имеет три вида операции - «Заявки», «Бюджет» и «Графики договоров» для установки соответствующих контрольных значений (лимитов).
Все лимиты записываются при проведении документа «Установка контрольных значений» в валюте сценария бюджетирования. При проведении заявок, бюджетных документов и документа «Дополнительные условия по договорам» (график платежей и начислений) сумма списания лимитов также пересчитывается в валюту сценария.
В документе можно установить отбор по измерениям, по которым ведется контроль. К примеру, для одних статей можно задать свои разрезы контроля (ЦФО и Проект), для других - другие (ЦФО, Контрагент, Организация).
Примечание. Для того, чтобы по определенным статьям оборотов не проводился контроль (не лимитируемые статьи), нужно для таких статей/проектов в форме элемента справочника «Статьи оборотов» на закладке «Настройка контроля» установить соответствующие флаги – можно отключить контроль по заявкам, контроль по бюджетам (отдельно для суммы и для количества), контроль графиков договоров или все виды контроля. Также отключить контроль можно для отдельных проектов - в справочнике «Проекты», и для отдельных сценариев - в справочнике «Сценарии бюджетирования».
Контроль заявок по бюджету
Если необходимо контролировать по бюджету заявки на расходование денежных средств и/или заявки на затраты, то в списке «Настройки программы (БИТ)» (раздел «Настройки (БИТ)») необходимо установить флаг:
1. «Контролировать заявку по бюджету» - для контроля заявок на расходование денежных средств по Бюджету движения денежных средств;
2. «Контролировать заявку на затраты по бюджету» - для контроля заявок затраты по Бюджету доходов и расходов.
3. «Контролировать заявку на закупку по бюджету» - для контроля заявок на закупку по Бюджету доходов и расходов и Бюджету закупок.
После ввода всех плановых данных по бюджетам, необходимо ввести документ «Установка контрольных значений» (раздел «Бюджетирование» - «Установка контрольных значений») с видом операции «Контроль заявок».
В форме документа «Установка контрольных значений» указывается Сценарий, по которому устанавливаются контрольные значения, и Период заполнения, за который эти значения будут заполнены по плановым данным. Например, если указать период заполнения «с 01.01.09 по 31.03.2009», то контрольные значения будут заполнены только за 1 квартал 2009 года, и соответственно контролировать суммы расходов денежных средств можно будет только в этом периоде, за остальные периоды лимиты будут считаться равными 0.
Периодичность контроля устанавливается в справочнике «Сценарии бюджетирования» на закладке Настройка контроля. Можно контролировать заявки помесячно, поквартально, за полугодие, год и т.п. Но также для отдельных статей или проектов можно установить свою периодичность непосредственно в документе "Установка контрольных значений". К примеру, все статьи кроме представительских расходов, можно контролировать в рамках каждого месяца, а статью Представительские расходы – в рамках года.
Также в документе реализована возможность устанавливать периодичность контроля «За весь период», не кратную месяцу, кварталу или году. При выборе такой периодичности нужно указать период, в рамках которого будет осуществляться контроль. К примеру, это может быть период проекта с 10.02.2020 по 30.06.2022. Контроль Заявок по бюджету будет осуществляться в целом за данный период.
По умолчанию сумма заявки контролируется по бюджету в разрезе статьи оборотов. Если, кроме этого, необходимо контролировать сумму заявки с учетом других аналитик бюджетирования (ЦФО, Проект и т.п.), то необходимо напротив нужных аналитик установить флаг в колонке «Контролировать по...».
В поле «Отбор» можно установить отбор по какой-либо аналитике (Статья оборотов, ЦФО и др.) или реквизиту аналитики (Вид статьи, Вид ЦФО и др.), для которых необходимо задать свое значение отклонения свои разрезы контроля или свою периодичность контроля.
При проведении документа все бюджетные данные будут зафиксированы в специальном регистре накопления «Контрольные значения бюджетов».
Это и будут контрольные значения, с которыми будут сравниваться суммы заявок на расходование денежных средств и заявок на затраты.
В Настройках программы БИТ реализована настройка «Учитывать сверхбюджетные заявки при контроле по бюджету». Если для настройки установить значение Нет (флаг снят), то при проведении заявок с установленным флагом «Сверх бюджета» лимиты не будут списываться, сумма будет фиксироваться в регистре "Контрольные значения бюджетов" в отдельной колонке «Сумма сверх лимита». Если флаг установить, то лимиты будут списываться при проведении документа с установленным флагом «Сверх бюджета».
В Константах (БИТ) реализована дополнительная настройка контроля «Заявок на затраты» по бюджету - флаг «БДР планируется с НДС». Данный флаг определяет способ планирования БДР для целей контроля по бюджету – с НДС или без НДС. Если флаг установлен, то при проверке на соответствие бюджету «Заявок на затраты» система анализирует сумму с НДС. Если флаг не установлен – анализируется сумма без НДС.
В Константах (БИТ) реализована дополнительная настройка контроля «Заявок на затраты» по бюджету - флаг «БДР планируется с НДС».
Данный флаг определяет способ планирования БДР для целей контроля по бюджету – с НДС или без НДС. Если флаг установлен, то при проверке на соответствие бюджету «Заявок на затраты» система анализирует сумму с НДС.
Если флаг не установлен – анализируется сумма без НДС.
Контроль по бюджетам
Для установки контроля бюджетов отдельных ЦФО или отдельных операционных бюджетов относительно бюджета, составленного в целом для компании, используется документ «Установка контрольных значений» с видом операции «Контроль бюджета».
Контроль осуществляется по сценариям бюджетирования: данные бюджета верхнего уровня (бюджета, составленного в целом для компании) должны быть введены по одному сценарию, а данные бюджетов более низких уровней (бюджеты ЦФО, операционные бюджеты и т.п.) - по другому сценарию.
В форме документа «Установка контрольных значений» в поле Сценарий указывается «контролирующий» сценарий бюджетирования, то есть тот, по которому будут контролироваться данные бюджетов более низких уровней. В поле Сценарий контролируемый указывается сценарий бюджетирования, данные которого будут контролироваться.
Реквизиты Отклонение суммы и Отклонение количества предназначены для установки допустимых отклонений от контрольных значений бюджета в абсолютной или относительной величине.
По умолчанию контроль бюджетов осуществляется только в разрезе статей оборотов. Если кроме этого необходимо контролировать один бюджет по данным другого бюджета с учетом других аналитик бюджетирования (ЦФО, Проект и т.п.), то необходимо в колонке «Контролировать по..» напротив нужных аналитик установить флаг.
В поле «Отбор» можно установить отбор по какой-либо аналитике (Статья оборотов, ЦФО и др.) или реквизиту аналитики (Вид статьи, Вид ЦФО и др.), для которых необходимо задать свое значение отклонения, свои разрезы контроля.
При проведении документа все бюджетные данные будут зафиксированы в специальном регистре накопления «Контрольные значения бюджетов». С этими значениями (данные бюджета верхнего уровня) будут сравниваться данные бюджетов более низких уровней.
Для того, чтобы «включить» контроль одного бюджета по данным другого бюджета, необходимо в «контролируемом» сценарии бюджетирования на закладке «Настройка контроля» добавить строку, в которой указать дату начала и дату окончания контроля. Если дату окончания не указать, контроль будет продолжаться неограниченное количество времени. Кроме того, в «контролируемом» сценарии нужно указать «Периодичность контроля» - в рамках какого периода производить контроль.
Далее, при проведении документов, отражающих плановые данные по «контролируемому» сценарию бюджетирования («Форма ввода бюджета», «Бюджетная операция» и др.), происходит сравнение с данными «контролирующего» сценария. Данные по «контролируемому» сценарию не будут записаны, если суммы оборотов превышают установленные контрольные значения. В строке сообщений при этом выдается соответствующее сообщение.
Для того, чтобы провести данные по «контролируемому» сценарию «сверх бюджета», в документах, отражающих плановые данные, предназначен соответствующий флаг «Сверх бюджета».
В Настройках программы БИТ реализована настройка «Учитывать сверхбюджетные операции при контроле по бюджету». Если для настройки установить значение Нет (флаг снят), то при проведении документов бюджетирования (Бюджетная операция, Форма ввода бюджета, Корректировка бюджета, Актуализация бюджета) с установленным флагом «Сверх бюджета» лимиты не будут списываться, сумма будет фиксироваться в регистре "Контрольные значения бюджетов" в отдельной колонке «Сумма сверх лимита». Если флаг установить, то лимиты будут списываться при проведении документа с установленным флагом «Сверх бюджета».
Контроль графиков договоров по бюджетам
Графики платежей и графики начислений по договорам создаются в документе «Дополнительные условия по договору». При проведении документа можно контролировать графики на соответствие бюджетам: график начислений контролировать по Бюджету доходов и расходов, а график платежей – по Бюджету движения денежных средств.
Для включения механизма контроля графиков договоров (графиков платежей и графиков начислений) необходимо в списке «Настройки программы (БИТ)» установить флаг «Контролировать графики договоров».
Для установки контроля графиков платежей и графиков начислений по бюджетам (БДР и БДДС) используется документ «Установка контрольных значений» (раздел «Бюджетирование») с видом операции «Контроль графиков договоров».
Документ «Установка контрольных значений» вводится после того, как введены плановые данные по бюджетам.
В форме документа указывается Сценарий, по которому устанавливаются контрольные значения, и Период заполнения, за который эти значения будут заполнены по плановым данным. Например, если указать период заполнения «с 01.01.09 по 31.03.2009», то контрольные значения будут заполнены только за 1 квартал 2009 года, и соответственно контролировать суммы расходов денежных средств можно будет только в этом периоде, за остальные периоды лимиты будут считаться равными 0.
Реквизиты Отклонение суммы и Отклонение количества предназначены для установки допустимых отклонений от контрольных значений бюджета в абсолютной или относительной величине. По умолчанию графики договоров контролируется по бюджетам в разрезе статей оборотов. Если, кроме этого, необходимо контролировать графики с учетом других аналитик бюджетирования (ЦФО, Проект и т.п.), то необходимо напротив нужных аналитик установить флаг в колонке «Контролировать по...».
В поле «Отбор» можно установить отбор по какой-либо аналитике (Статья оборотов, ЦФО и др.) или реквизиту аналитики (Вид статьи, Вид ЦФО и др.), для которых необходимо задать свое значение отклонения, свои разрезы контроля.
При проведении документа все бюджетные данные будут зафиксированы в специальном регистре накопления «Контрольные значения бюджетов». Это и будут контрольные значения, с которыми будут сравниваться суммы графиков платежей и графиков начислений в документе «Дополнительные условия по договору».
В Константах (БИТ) реализована дополнительная настройка контроля графика начислений по бюджету - флаг «БДР планируется с НДС».
Данный флаг определяет способ планирования БДР для целей контроля по бюджету – с НДС или без НДС. Если флаг установлен, то при проверке на соответствие бюджету графика начислений в документе «Дополнительные условия по договору» система анализирует сумму с НДС. Если флаг не установлен – анализируется сумма без НДС.
Для того, чтобы провести документ «Дополнительные условия по договору» сверх бюджета, необходимо установить в документе соответствующий флаг - «Сверх бюджета». Флаг «Не контролировать по бюджету» устанавливается, если какой-то конкретный документ не нужно контролировать по бюджету, например, если графики относятся к периоду, за который еще не введены плановые данные.
