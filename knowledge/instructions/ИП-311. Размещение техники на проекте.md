# Форма списка документов «Размещение техники на проекте»
Документ «Размещение техники на проекте» в системе отражает факт. размещения техники на объекте (-ах), также закрепление техники за МОЛом.
- Для создания документа «Размещение техники на проекте» необходимо открыть раздел «АТ: Автотранспорт и строительная техника», далее в подразделе «Работа техники» на форме найти документ «Размещение техники на проекте» (Рисунок А1).
Рисунок А1. Открытие документа размещение техники на проекте.
- Откроется список документов «Размещение техники на проекте», где окно (форму списка) можно разделить на три части, «Командная панель», «Область отборов документов», «Список документов» (Рисунок А2).
Рисунок А2. Форма списка документов «Размещение техники на проекте».
# Создание нового документа «Размещение техники на проекте» и его заполнение реквизитов
- Для того, чтобы создать новый документ нажимаем на кнопку [Создать] на командной панели (Рисунок Б1).
Рисунок Б1. Создание размещение техники на проекте
- Откроется форма заполнения документа, где необходимо заполнить поля «Шапки» документа.
Рисунок Б2. Заполнение «шапки» документа.
В форме документа Размещение техники на проекте заполняются следующие реквизиты:
- Организация – организация, учет техники которой ведется в информационной базе, обязательное поле, заполняется из одноименного справочника доступных организаций; (Рисунок Б2)
- Дата – дата создания документа;
- Раздел «Техника» состоит из командной панели и табличной части документа (Рисунок Б3).
Рисунок Б3. Раздел «Техника».
В командной панели присутствует две активные кнопки «Добавить» и «Очистить» (Рисунок Б4).
Рисунок Б4. Командная панель раздела «Техника».
- Добавить – Команда добавляет новую строку в табличную часть документа для закрепления техники за проектом или МОЛом «Техника».
- Очистить – Очищает табличную часть документа.
Табличная часть документа состоит из шести колонок (Рисунок Б5 и Рисунок Б6):
- N – Отражается номер строки в табличном документе.
- Техника – Выбранная техника для размещения на проекте или закрепления за МОЛом.
- Подразделение – Выбирается подразделение организации из отбора в шапке документа, выбранное поле закрепляет технику по данному подразделению.
- Проект – Выбирается проект для размещения техники, выбранное поле закрепляет технику по данному проекту.
- Номенклатурная группа – Выбирается для отображения в путевых листках по выбранной технике.
- МОЛ – Материально ответственное лицо за выбранную технику.
Рисунок Б5. Табличная часть документа.
Рисунок Б6. Табличная часть документа.
# Подвал документа
- Ответственный – заполняется автоматически автором документа;
- Комментарий – используется для пометок и дополнительной информации по документу.
Рисунок В1. Пример заполнения подвала документа.
# Завершение формирования документа и настройки БИТ
После заполнения основных полей и табличной части, необходимо записать документ, для этого нажмите на кнопку [Записать] на командной панели (Рисунок Г1).
Рисунок Г1. Запись документа.
По окончании заполнения и проверки документа необходимо его «Провести» (Рисунок Г2).
Рисунок Г2. Проведение документа.
Для проверки размещения или закрепления выбранной техники, необходимо провалится в карточку техники (Рисунок Г3), перейти на вкладку «Закрепление техники» (Рисунок Г4).
Рисунок Г3. Карточка номенклатуры.
Рисунок Г4. История размещения и закрепления техники.
