# ИП-. Инструкция пользователя. Бюджетная операция

> Источник: `ИП-. Инструкция пользователя. Бюджетная операция.docx`

Документ «Бюджетная операция»
Для отражения планируемого движения средств предприятия по определенному сценарию можно использовать документ «Бюджетная операция» (раздел «Бюджетирование»).
Планирование любых данных всегда происходит для определенного сценария. Если сценариев несколько, данные по каждому из них планируются отдельно. Поэтому в документе поле «Сценарий» является обязательным для заполнения.
Указываются Валюта, в которой будут вводиться данные в документ и курс валюты. Суммы могут вводиться в документ в единицах, в тысячах или в миллионах. Нужное значение указывается в поле «Суммы в».
Распределение по аналитикам и периодам
При вводе данных может потребоваться распределить сумму и/или количество по аналитике. Например:
- по ЦФО или проектам;
- по периодам (например, годовую сумму распределить по месяцам).
В табличной части документа распределение выполняется по любой аналитике, кроме «Статьи оборотов».
Как выполнить распределение:
- Выделите ячейку в колонке с нужной аналитикой (например, «Проект»).
- Нажмите правую кнопку мыши, чтобы открыть контекстное меню.
- Выберите команду «Распределить».
После нажатия «Распределить» откроется форма, в которой:
- Нажмите «Подбор» и выберите проекты — они добавятся в табличную часть.
- Для каждого проекта укажите процент распределения суммы.
- Если нужно распределить сумму равномерно между всеми проектами, нажмите «Равномерно».
Если настроенный профиль распределения потребуется использовать неоднократно, его можно сохранить.
Для этого:
- Нажмите кнопку «Записать» — профиль будет сохранён в справочнике «Профили распределения».
- Затем нажмите кнопку «Распределить», чтобы выполнить распределение.
Разовое распределение (без сохранения профиля)
Если профиль не понадобится в будущем, распределение можно выполнить единовременно. Для этого после заполнения в табличной части аналитик и процентов сразу нажмите кнопку «Распределить». Сумма будет распределена по указанным проектам в соответствии с заданными процентами.
Распределение по периодам (например, годовой суммы по месяцам)
- Выделите ячейку в колонке «Период».
- Нажмите правую кнопку мыши и в контекстном меню выберите «Распределить».
- Укажите периоды и процент распределения (аналогично распределению по аналитикам).
- Нажмите кнопку «Распределить».
Использование сохранённых профилей
Все записанные профили хранятся в справочнике «Профили распределения». При работе с документами бюджетирования вы можете выбрать нужный профиль непосредственно из формы распределения.
По кнопке «Изменить» можно изменить значения реквизитов табличной части документа.
При нажатии кнопки открывается форма обработки, в которой в верхнем поле указывается аналитика, которую необходимо изменить, а в нижнем – выделяются флажками строки, в которых нужно произвести замену.
Далее необходимо нажать кнопку «Выполнить» или «Выполнить и закрыть», в табличной части документа будет произведена замена. Если необходимо заменить только конкретные значения аналитики, например, только ЦФО «Атлантика» заменить на ЦФО «Атлантика-Снабжение», то необходимо в поле «Начальное значение» выбрать конкретное значение ЦФО «Атлантика» и указать конечное значение «Атлантика-Снабжение».
В этом случае в табличной части документа заменятся только значения «Атлантика», остальные значения ЦФО останутся без изменений.
Режим зависимых оборотов (вариант формирования зависимых оборотов по статьям оборотов) может быть автоматическим или можно установить, что зависимые обороты не будут формироваться. Формирование зависимых оборотов будет рассмотрено далее, в разделе «Планирование зависимых статей оборотов».
В поле «Параметр норм» выбирается вид произвольного параметра (из плана видов характеристик «Виды произвольных параметров») – для автоматической подстановки норм при вводе операции по статьям, предусматривающим количественно–суммовой учет.
В табличной части документа заполняются необходимые аналитики бюджетирования.
В поле «Период» указывается начало периода планирования в зависимости от периодичности выбранного сценария, например, первое число очередного месяца.
В поле «Статья оборотов» указывается статья оборотов по бюджетам, по которой производится планирование. Для статьи оборотов указывается ее плановое значение на заданный период в рамках указанного сценария. При этом если по статье ведется количественный учет, необходимо указать количество. Также в табличной части, при необходимости, заполняются другие аналитики: ЦФО, Контрагент, Договор и др.
По кнопке «Заполнить» возможно автоматическое заполнение документа с помощью копирования ранее введенных в систему данных по любому сценарию бюджетирования. Описание механизма копирования бюджета можно прочитать в разделе Документ «Форма ввода бюджета», подраздел «Копирование бюджета». Также, по кнопке «Заполнить» возможно автоматическое заполнение данных по произвольным источникам (настройка источников данных выполняется при внедрении информационной системы).
Данные бюджетной операции могут быть заполнены по данным графиков платежей и графиков начислений, сформированных в документах «Дополнительные условия по договорам». Для этого предназначена кнопка «Заполнить – Копирование данных графиков договоров».
