# Настройка отборов в 1С БИТ

Для быстрого поиска по списку документов необходимо настроить отборы.

**Шаг 1.** Откройте список документов, нажмите кнопу «Ещё» - «Настроить список».

**Шаг 2.** Откроется форма «Настройка списка», в которой необходимо перейти на вкладку «Отбор». Форма разделена на две части: слева – доступные поля для выбора и справа – поля, которые выбраны для отбора, они отображаются в шапке документа для быстрого поиска по документам.

**Шаг 3.** Выберите нужное поле для отбора, щелкните по нему два раза левой кнопкой мыши для того, чтобы оно было перенесено в правую сторону формы.

**Шаг 4.** При необходимости можно установить разный вид сравнения значения, которое Вы будете вводить для поиска. Например, значение «Содержит» позволяет искать документы, в которых поле содержит указанное слово.

**Шаг 5.** Нажмите кнопку «Завершить редактирование», нужный отбор появится в шапке документа.
