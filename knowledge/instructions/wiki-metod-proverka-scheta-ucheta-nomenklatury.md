# Проверка корректности счета учета нормализованной номенклатуры

Код инструкции: ``
Источник: `wiki.hg.loc/spaces/1C`
Раздел: Методические материалы

---

Если после нормализации номенклатуры при проведении документа программа сообщает что **"Некорректно заполнена колонка "Количество" в строке %N% списка "Материалы". Указанное количество превышает остаток. Остаток: 0; Не хватает: %N%"** (рисунок 1), но при этом остаток товара есть на другом счете учета, можно проверить табличную часть «Материалы» и заменить счет учета, на котором есть остатки.

Для этого нажмите кнопку «Заполнить», далее выберите «Заполнить счет учета по остаткам», система предложит заменить счет учета табличной части номенклатуры - нажмите «Да». В табличной части будет перезаполнен счет учета.

Обработка проверит остатки номенклатуры по счетам и заполнит тот счет, на котором максимальное количество остатков.
