# Форма списка документов «Расходный ордер»
- Для создания Расходного ордера (далее по тексту РО) пользователь должен в 1С.БИТ перейти в блок «Снабжение и склад», далее в разделе «Склад» выбрать «Расходные ордера» (Рисунок А1).
- Рисунок А1. Открытие расходного ордера.
- Откроется форма списка документа «Расходные ордера», где визуально форму можно разделить на 3 части «Командная панель», «Область отборов», «Список документов» (Рисунок А2).
- А2. Форма списка документа «Расходный ордер»
## 1.1 Командная панель
- Командная панель представлена различными кнопками для взаимодействия с документами. Рассмотрим за что отвечает каждая команда по порядку слева направо (Рисунок А2, Таблица А1).

|  | Команда «Дополнительные сведения» – раздел, содержащий дополнительные реквизиты, добавленные для этого вида документа. |

|  | Команда "База знаний" - открывает внутренний портал wiki.hg.loc со ссылкой на данную инструкцию. |
|  | Команда «ЭДО» - содержит в себе команды "Просмотреть электронный документ", "Подписать электронный документ" "Текущие дела ЭДО. Ознакомиться с функционалом данных команд можно по ссылке |

## 1.2 Область отборов
Область отборов предназначена для работы со списком документов, позволяет отбирать документы по заданным параметрам (Рисунок А2).
Рисунок А2. Область отборов на форме списка
Отборы можно производить только по реквизитам, указанным в шапке или подвале документа, а также, по дополнительным сведениям, нельзя добавить в отбор реквизиты табличной части документов. На рисунке А3 зеленой рамкой выделены реквизиты, по которым на форме списка можно делать отбор.
Рисунок А3. Реквизиты доступные для работы с отборами на форме списка.
Для того чтобы добавить свой отбор в шапку документа необходимо нажать справа кнопку «Ещё» => «Настроить список» => вкладка «Отбор» => Выберете реквизит, по которому ходите осуществлять отбор и перенесите его вправо => После завершения редактирования он появится в верхней части формы списка (Рисунок А4).
Рисунок А4. Настройка дополнительных отборов на форме списка.
## 1.3 Список документов
Список документов – это таблица с документами одного вида, в данном случае документы «Расходный ордер».
В самом журнале установленная сортировка обозначается стрелочкой (Рисунок А5). Для того, чтобы изменить сортировку – достаточно щелкнуть мышкой один раз на заголовке столбца, и сортировка тут же будет установлена по нему. Направление стрелки – показывает, как происходит сортировка по возрастание или убыванию (Рисунок А5).
Рисунок А5. Сортировка в журнале документов
Расположение и количество колон в списке можно менять исходя из потребностей (Рисунок А6). Для этого нажмите кнопку «Ещё» => Выберете команду «Изменить форму» => Откроется окно «Настройка формы» => Раскройте строку с названием «Список» => Далее можете менять состав колонок, изменять их расположение (Синие стрелочки сверху списка) (Рисунок А6).
Рисунок А6. Выбор столбцов для формы списка
Но учите, что большое количество колонок замедляет работу формы. Для поиска рекомендуется встать на ту колонку по которой будет осуществляться поиск и нажать ALT + F. Откроется окно поиска, которое поможет сократить поиск в пределах колонки (Рисунок А7).
А7. Поиск по форме.
# Заполнение шапки документа
Для создание нового документа в командной панели нажмите на кнопку «Создать» (Рисунок Б1).
- Рисунок Б1. Форма списка документов «Расходный ордер»
! Если в создаваемом документе материалы будут списываться по разным номенклатурным группам, счетам затрат, подразделениям затрат, то заполнение этих аналитик необходимо производить в табличной части МПЗ документа для каждой позиции отдельно.
! Если в документе материалы будут списываться на один счет затрат и подразделение затрат, и номенклатурную группу, то заполнять эти поля в табличной части не нужно, достаточно один раз их заполнить в шапке документа.
Рассмотрим заполнение документов с различными видами операций.
## Вид операции «На затраты»
- В открывшейся форме заполним поля шапки документа (Рисунок Б2).
- Рисунок Б2. Заполнение шапки документа с видом операции «На затраты».
- Номер – присваивается программой автоматически.
- Дата – указать дату фактического расхода со склада.
- Организация – выбрать соответствующую организацию.
- Вид операции => На затраты – при выборе этого вида операции создается документ по БУ «Расход материалов».
- Способ отраж. затр. – указать счет затрат.
- Физ. лицо – ответственный исполнитель, со склада которого материалы или оборудование списываются на затраты.
- Номенкл. группа – выбрать номенклатурную группу из справочника.
- Подразделение – заполнить подразделение списания материалов. Для корректной установки подразделения смотрите раздел соответствие счетов затрат и подразделений затрат (раздел «Соответствие счетов затрат и подразделений затрат» по своей организации).
- Склад – заполнить склад, с которого происходит списание материалов.
- Бух. учет - галочка устанавливается, если необходимо на основании приходного ордера создать документ по БУ. В нашем случае нужно устанавливать всегда.
После заполнения шапки документа, заполните табличную часть согласно раздела 3 Заполнение табличной части документа».
## Вид операции «Передача в эксплуатацию»
Документом «Расходный ордер: в эксплуатацию» отражается передача специальных материалов со склада и закрепление их за физическим лицом (МОЛом). Заполним шапку документа (Рисунок В1).
- Рисунок В1. Заполнение шапки с видом операции «Передача в эксплуатацию».
- Номер – присваивается программой автоматически.
- Дата – указать дату фактического расхода со склада.
- Организация – выбрать соответствующую организацию.
- Вид операции => Передача в эксплуатацию – при выборе этого вида операции создается документ по БУ «Передача материалов в эксплуатацию».
- Способ отр. расходов. – указать способ отражения расходов из справочника при необходимости.
- Физ. лицо – МОЛ, которому передаются материалы в эксплуатацию.
- Номенкл. группа – выбрать номенклатурную группу из справочника.
- Подразделение – заполнить подразделение списания материалов.
- Склад – заполнить склад, с которого происходит списание материалов.
- Бух. учет – галочку устанавливать всегда.
- Операция по ден. документам – не используется.
- Объект строительства – указывается только в том случае, если материалы будут списываться на объект строительства. Значение выбирается из справочника по своей организации. При передаче СИЗ сотруднику данное поле заполнять не нужно.
После заполнения шапки документа, заполните табличную часть согласно раздела 3 «Заполнение табличной части документа».
## Вид операции «Недостачи»
- Расходным ордером с видом операции «Недостачи» производится корректировка учетных данных в системе по количеству и стоимости материалов, по которым обнаружены (в результате инвентаризации) недостачи на складах организации. Заполним шапку документа (Рисунок Г1).
- Рисунок Г1. Заполнение шапки с видом операции «Передача в эксплуатацию».
- Номер – присваивается программой автоматически.
- Дата – указать дату фактического расхода со склада.
- Организация – выбрать соответствующую организацию.
- Вид операции => Недостачи – при выборе этого вида операции создается документ по БУ «Списание товаров, материалов».
- Подразделение – заполнить подразделение списания материалов.
- Склад – заполнить склад, по которому необходимо произвести корректировку.
- Бух. учет – Если нужно создать документ «Списание товаров, материалов», то галочку необходимо установить.
- Инв. МПЗ – ссылка на документ инвентаризации, если расходный ордер формируется по ее результатам.
- – Операция по ден. документам – не используется.
- Если заполнен реквизит «Инв. МПЗ», либо по кнопке [Заполнить/ Дополнить по остаткам]. Табличная часть может быть заполнена по кнопке [Ввести данные: Заполнить по инвентаризации] (Рисунок Г2).
- Рисунок Г2. Заполнить по инвентаризации.
- По тем позициям, которые были оприходованы в программе со ссылкой на заявку на МПЗ, при формировании расходного ордера с видом операции «Недостачи» может быть сформировано информационное сообщение о том, что по выбранным позициям не хватает свободных остатков, и такой документ не проведется (Рисунок Г4).
- Рисунок Г4. Информационное сообщение об отсутствии свободных остатков.
- По этим позициям необходимо снять установленные резервы с заявки.
- По кнопке [Снятие резерва по недостачам], которая находится в правом верхнем углу документа (Рисунок Г5).
- Рисунок Г5. Команда снятия резерва по недостачам.
- Откроется обработка, в табличной части которой «Необходимо снять с резерва» отражаются позиции номенклатуры, по которым необходимо снять резерв (Рисунок Г6).
- Рисунок Г6. Снятие резерва по недостаче.
- В табличной части «Резервы» отображаются заявки на МПЗ по выбранным МПЗ.
- В табличной части «Документы снятия с резерва» будут отражаться документы, которыми будет снят резерв по заявке на материалы. Последние формируются по кнопке [Снять резерв] (Рисунок Г7).
Рисунок Г7. Снятие резерва по недостачам.
- После выполненных операций расходный ордер: недостачи проведется
## Вид операции «Передача подрядчику»
Данный вид операции предназначен для отражения передачи МПЗ подрядчику в переработку МПЗ (Рисунок Л1).
- Рисунок Л1. Заполнение шапки с видом операции «Передача подрядчику».
- – Номер – присваивается программой автоматически.
- – Дата – указать дату фактического расхода со склада.
- – Организация – выбрать соответствующую организацию.
- – Вид операции => Передача подрядчику – при выборе этого вида операции создается документ по БУ «Передача сырья в переработку».
- – Подразделение – заполнить подразделение.
- – Склад – склад, с которого будут переданы материалы в переработку;
- – Бух. учет – Установить галочку Бух. учет, для создания документа по БУ.
- – Контрагент – подрядчик, которому будут переданы материалы (оборудование);
- – Договор контрагента - договор с подрядчиком.
- – Задание - заполняется автоматически, если РО формируется на основании задания на перемещение. Если документ заполняется по заданию на перемещение, тогда табличная часть заполняется автоматически, в иных случаях для заполнения можно воспользоваться кнопкой [Подбор МПЗ];
- – Номенклатурная группа - объект строительства (реквизит не является обязательным для заполнения). Если в шапке документа не заполнить реквизит «Номенклатурная группа», то его можно указать в табличной части документа по каждой позиции отдельно.
После заполнения шапки документа, заполните табличную часть согласно раздела 3 «Заполнение табличной части документа».
- Далее для отражения документа по БУ обратитесь к разделу 4 «Отражение документов по БУ».
## Вид операции «Расход ГСМ»
Документ РО с видом операции «Расход ГСМ» создается автоматически на основании документа «Путевой лист» и недоступен для редактирования. Ручное создание расходного ордера с этим видом операции необходимо создавать для корректировки заправок прошлых периодов (см. инструкцию по созданию и списанию заправок прошлых периодов). Также документ с этим видом операции можно использовать, если в путевом листе невозможно рассчитать количество топлива к списанию из-за отсутствия формулы расчета. Например, для ДЭС и дополнительного оборудования.

- – Подразделение – заполнить подразделение.
- – Склад – заполнить склад, с которого производится возврат.

## Вид операции «Принятие к учету ОС»
Документ расходный ордер с видом операции "Принятие к учету ОС" необходим для списания поступившего основного средства в управленческом учете, поскольку ОС ведутся только по бухгалтерскому учету. Этот вид операции НЕ создает документ по БУ, галочку Бух. учет устанавливать не нужно. Документ с этим видом операции можно связать с документом БУ вручную нажав на значок "УУ → БУ связать" на форме документа (рисунок Ё1).
Рисунок Ё1. Связь с документом БУ.
## Вид операции «Передача оборудования в монтаж»
Документ предназначен для включения стоимости оборудования и комплектующих, требующих монтажа, в расходы, формирующие первоначальную стоимость объектов основных средств.  При выборе данного вида операции в управленческом учете (Рисунок Ж1) и отражении его в бухгалтерском учете создается аналогичный документ "Передача оборудования в монтаж".
Рисунок Ж1. Реквизитный состав документа, пример заполнения.
При вводе документа в шапке нужно указать следующие реквизиты:
- Дата - дата операции.
- Подразделение - обязательное поле, значение выбирается из справочника "Подразделения". Заполняется в шапке или в табличной части документа.
- Способ отражения затрат - обязательное поле, статья затрат для учета расходов по строительству. Заполняется в шапке или в табличной части документа.
- Физ. лицо - обязательное поле, МОЛ ответственный за монтаж оборудования.
- Вид операции - Передача оборудования в монтаж.
- Номенклатурная группа - выбирается необходимая номенклатура группа из справочника.
- Объект строительства - объект строительства, на котором накапливаются затраты по строительству основных средств.
- Склад - склад, с которого списывается оборудование.
- Признак "Бух. учет" - установить для возможности отразит документ по БУ (по умолчанию установлено).
- Признак "Операции по ден. документам" и "ТО и ремонт зданий и сооружений" - не применим к данному виду операции.
- Техника - заполнение поля не применимо к данному виду операции.
Рисунок Ж2. Пример заполнения табличной части
В табличном поле МПЗ указывается список оборудования (Рисунок Ж2), которое предается в монтаж:
Как заполнить табличную часть указанно в разделе 3 настоящей инструкции «Заполнение табличной части документа».
- Номенклатура - обязательное поле, указывается передаваемое оборудование.
- Ед. измерения - заполняется автоматически из выбранной номенклатуры.
- Количество - обязательное поле, указывается количество передаваемого оборудования.
- Цель расхода - не заполняется для данного вида операции.
- Заявка на МПЗ - заполняется автоматически, при условии, что выбранная номенклатуры есть в резерве по остаткам на складе.
- Объект строительства - если в одном документе необходимо отразить передачу оборудования в монтаж по разным объектам строительства, то заполнять нужно в табличной части, иначе можно его заполнить только в шапке документа.
- Подразделение - если в одном документе необходимо отразить передачу оборудования в монтаж по разным подразделениям, то заполнять нужно в табличной части, иначе можно его заполнить только в шапке документа.

Рисунок М2. Подбор МПЗ.
- верхняя рабочая область – область отборов. При заполнении поля «Заявка на МПЗ», в левой рабочей области отобразится только та номенклатура, которая указана в выбранной заявке на МПЗ. Для корректного подбора материалов всегда устанавливаться галочку «С учетом резервов». Поле «Поиск» позволяет искать номенклатуру в справочнике.

- левая рабочая область – элементы справочника «Номенклатура», которые входят в группу, выделенную справа, либо все элементы справочника, если флаг «Показывать по иерархии» не установлен. Порядок отображения данных в описываемой области определяется кнопками отображать остатки: Все /В наличии/Доступно, а также по реквизиту «На дату (конец дня)» и «Дата из формы владельца»;
- нижняя область обработки – элементы, отобранные пользователем для переноса в документ (может быть скрыт по кнопке «Скрыть подобранные»). Если область не отображается, необходимо нажать кнопку «Отображать подобранные».

Рисунок М3. Форма подбора количества.

Рисунок М4. Заполненная табличная часть «Расходного ордера».
- Номенклатура – материал.
- Ед. изм. – единица измерения материала.

- Количество – количество по накладной.
- Заявка на МПЗ – подставляется автоматически из формы подбора МПЗ.
