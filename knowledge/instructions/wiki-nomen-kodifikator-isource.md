# Кодификатор Isource. Эталон и товарные

Код инструкции: ``
Источник: `wiki.hg.loc/spaces/1C`
Раздел: Нормализованный справочник номенклатуры

---

**Кодификатор ISource** - автоматически формируемый уникальный внутренний код записи в справочнике.

Он формируется по следующим правилам:
- первые десять знаков отражают положение номенклатурной записи в классификаторе — 16AABBCCDD,
- все записи в нормализованном справочнике блока Development всегда начинаются с 16,
- AA, BB, CC, DD – сегменты кода, соответствующие уровням классификатора,
- первая исторически созданная **эталонная запись** получает свой «порядковый номер» после первой точки в кодификаторе — 16AABBCCDD**.1**,
- все **товарные** записи, относящиеся к эталону, получают свои номера после второй точки — 16AABBCCDD**.1.1**.

При настроенном переключателе отбора по полю **Все (Development)**, рекомендуется в табличной части выбрать сортировку номенклатурных записей по критерию **Кодификатор ISource** для отображения в списке связанных между собой товарных и эталонных позиций в рамках категории.

Например:
- позиция **Круглогубцы никелированные 160ММ CrV** с кодификатором ISource **1636030400.1** является **эталоном**.
- товарная позиция **Круглогубцы никелированные Matrix Nickel 17355 160ММ CrV** получила кодификатор **1636030400.1.1**.
