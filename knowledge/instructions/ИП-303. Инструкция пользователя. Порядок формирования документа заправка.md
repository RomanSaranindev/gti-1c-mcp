# Форма списка документа «Заправка»
Документ «Заправка (Приходный ордер)» предназначен для оформления факта заправки сторонней АЗС. Документ может быть создан в путевом листе на закладке «ГСМ» или непосредственно из журнала «Заправки» по кнопке [Создать]. Рассмотрим порядок заполнения документа из журнала «Заправки».
- Для создания документа «Заправка» необходимо открыть раздел «АТ: Автотранспорт и строительная техника», далее в подразделе «ГСМ» найти документ «Заправка» (Рисунок А1).
Рисунок А1. Открытие документа заправка.
- Откроется список документов «Заправки», где визуально окно (форму списка) можно разделить на три части, «Командная панель», «Область отборов документов в списке», «Список документов» (Рисунок А2).
Рисунок А2. Форма списка документов «Заправочные ведомости».
# Создание нового документа «Заправка» и заполнение его реквизитов
- Для того, чтобы создать новый документ нажимаем на кнопку [Создать] на командной панели (Рисунок Б1).
Рисунок Б1. Создание заправочной ведомости.
- Откроется форма создания документа «Приходный ордер», где необходимо заполнить поля «Шапки» документа.
– Номер – присваивается программой автоматически.
– От – указать дату фактического поступления на склад-технику.
– Организация – обязательное поле заполняется из одноименного справочника (Рисунок Б2).
– Вид операции – указывать всегда «Заправка».
- Контрагент – выбрать поставщика топлива из справочника «Контрагенты».
- Физ. лицо – указать водителя.
- МОЛ – указать материально-ответственное лицо (водитель или другое лицо).
Рисунок Б2. Пример заполнение организации и даты документа, вид операции.
- Склад – выбрать технику, на который заливается топливо. Для заполнения поля склад нажимаем на стрелочку списка выбора (рисунок Б3), переходим по синей ссылке «Показать все», далее откроется форма подбора «Склада» из справочника склады, переходим к полю «Отображение склад / техника» ставим переключатель на значение «Техника», раскрываем группу «Группа складов-техники (БИТ)» (можно воспользоваться поиском по номеру машины), встаем на строку с необходимой техникой, далее нажимаем кнопку [Выбрать].
- Рисунок Б3. Выбор склада-техники.
- Договор контрагента – выбрать договор поставщика ГСМ из справочника «Договоры».
- Бух. учет - галочка устанавливается, если необходимо на основании заправки создать поступление товаров или авансовый отчет. В нашем случае нужно устанавливать всегда.
- Номер чека – заполнить номер чека, выданного от АЗС.
- Дата чека – заполнить дату чека, выданного от АЗС.
- Подразделение – заполняем подразделение, к которому привязана выбранная Техника.
Рисунок Б4. Выбор склада, договора, данных чека.
- Способ расчета – указать способ расчета – наличный или безналичный. По умолчанию значение данного переключателя стоит «Наличные».
- Пластиковая карта – выбрать топливную карту. Поле доступно, если способ расчета указан «Безналичные».
- ! При безналичном способе расчета пользователь должен указать номер карты (справочник «Пластиковые карты») (рисунок Б5), с которой необходимо списать топливо и пополнить бак техники. Важно для отражения заправки по карте «баланс» (количество топлива) карты должен быть положительным и достаточным для списания (Баланс устанавливается документом «Корректировка баланса пластиковых карт»).
- Рисунок Б5. Выбор способа расчета
# Заполнение табличной части МПЗ
Для заполнения табличной части МПЗ в документе заправка необходимо в командной панели табличной части (Рисунок В1) нажать кнопку [Добавить].
Рисунок В1. Добавление строки в табличную часть.
После добавление строки необходимо заполнить следующие реквизиты:
- Номенклатура – выбрать топливо в литрах.
- Ед. изм. – подставится автоматически.
- К. – коэффициент – подставляется автоматически из номенклатуры, в основном равен единице.
- Количество – заполнить количество литров.
! Если способ расчета «Наличные», тогда поля табличной части «Цена», «Сумма», «%НДС», обязательны к заполнению по данным чека (Рисунок В2). Если способ расчета «Безналичные», эти поля заполнять не нужно.
- Цена – заполнить цену по чеку.
- Сумма – заполнится автоматом.
- Сумма НДС – заполнить сумму НДС по чеку.
- Всего – посчитается автоматически.
Рисунок В2. Заполнение полей при способе расчета «Наличные».
После заполнения всех полей, проводим документ (Рисунок В3).
Рисунок В3. Проведение документа.
# Прикрепить чек заправке
Для подтверждения факта заправки в документ «Заправка» необходимо вложить сканированную копию бумажного чека. Для этого отсканируйте чек, поместите его на сетевой диск и нажмите иконку «Присоединённые файлы» (Рисунок Г1). Откроется форма присоединенные файлы, где через кнопку [Добавить] => [Файл с компьютера] вкладываем файл, находящийся на сетевом диске.
Рисунок Г1. Присоединение чека заправки.
# Связь заправки с поступлением в бухгалтерском учёте
Создать связь можно как из документа, так и массово из формы списка. Рассмотрим процесс создания связи с бухгалтерским учётом, для этого из документа «Заправка» требуется создать связь с документом «Поступление (акт, накладные)». На командной панели нажмите на иконку «УУ -> БУ Связать» (Рисунок Д1). Откроется форма выбора документа «Поступление (акт, накладные)» (Рисунок Д2), где необходимо найти ту УПД, по которой осуществлена поставка топлива.
Рисунок Д1. Связь документа с бухгалтерским учётом.
Для массового создания связи документов «Заправка» с УПД необходимо открыть форму списка. Как открыть форму списка смотрите раздел 1 данной инструкции. Чтобы связать документы с БУ необходимо выделить документы, которые хотим связать (для выделения нескольких документов зажмите кнопку Shift или Ctrl на клавиатуре), далее нажать на значок «УУ -> БУ Связать» (Рисунок Д2).
Рисунок Д2. Создание связи с БУ.
