# Контур.Фокус

Код инструкции: ``
Источник: `wiki.hg.loc/spaces/1C`
Раздел: Контур.Фокус

Данная инструкция описывает пошаговый алгоритм запуска инструмента **Контур.Фокус** и создания нового списка контрагентов для проверки.

## 1. Запуск модуля

1. Откройте систему (1С БИТ) и обратите внимание на левое боковое меню.
2. В списке модулей найдите **Контур.Фокус** и нажмите на него.
3. В открывшемся окне нажмите кнопку **«Запустить модуль»**.

После выполнения этих действий запустится стартовая страница инструмента.

## 2. Точечная проверка контрагентов

Для точечной проверки контрагента необходимо выполнить следующие действия:

1. Найдите поле для ввода ИНН — оно предназначено для ручного указания номера.
2. Введите ИНН контрагента в это поле.
3. Нажмите кнопку «Проверить».
4. Дождитесь сформированного отчёта.

После выполненных действий сформируется подробная сводка по контрагенту.

## 3. Создание списка контрагентов (по фильтрам)

Для создания списка контрагентов по фильтрам необходимо:

1. Откройте Контур.Фокус и нажмите кнопку «Создать список».
2. Программа предложит два варианта:
   - «С настройками пользователя»
   - «По шаблону»
   
   Выберите «С настройками пользователя».

3. В открывшейся форме настройки списка:
   - **Заполните наименование списка** (обязательно)
   - При желании заполните краткое описание
   - Укажите тип контрагентов: «Юрлица» или «Физлица»
   - Рядом с полем «Контрагент» нажмите на значок «шестерёнка» для задания фильтров

4. **Настройте нужные фильтры**. Например:
   - Дебиторская задолженность: отметьте «есть задолженность» или «нет», укажите сумму, срок долга
   - Активность: поставьте галочку для контрагентов, с которыми есть активы и документы
   - Организация: при необходимости отметьте «отобрать по конкретной организации»

5. После выбора всех нужных галочек нажмите «ОК».

6. **Дополнительные настройки** (по желанию):
   - В разделе «Дополнительные поля» поставьте галочки для суммы задолженности и дней просрочки
   - Для настройки доступа для других пользователей нажмите на гиперссылку в дополнительных настройках

7. В разделе «Что проверять»:
   - «Реквизиты» — отметьте галочками, что показывать
   - «Рисковые факторы» — нажмите на «шестерёнку», чтобы настроить маркеры проверки
   - «Связи» — поставьте галочку для проверки реквизитов по связям с другими юрлицами

8. Нажмите кнопку **«Сохранить»**. Программа будет формировать список примерно 3–4 минуты.

9. После сохранения откроется форма со списком контрагентов, отобранных по заданным фильтрам. Для проверки нажмите кнопку **«Проверить список»**.

После проверки отобразится рейтинг контрагента. При нажатии на него справа отобразится вся подробная информация.

## 4. Создание списка определённых контрагентов (ручной отбор)

В соответствии с инструкцией выше:

1. Откройте Контур.Фокус и нажмите кнопку «Создать список».
2. Выберите вариант «С настройками пользователя».
3. В открывшейся форме введите наименование списка.
4. Укажите тип контрагентов (например, «Юр.лица»).
5. Рядом с полем «Контрагенты» нажмите на значок «шестерёнка».
6. В появившихся настройках выберите **«Ручной отбор контрагентов»**.
7. Нажмите кнопку «Добавить» и вручную введите перечень контрагентов.
8. Нажмите «Окей» — подтвердите ручной отбор.

**Примечание:** Никакие другие фильтры (задолженность, активность, сроки и т.д.) ставить не нужно.

9. Снова нажмите «Окей» — закройте форму настроек фильтра.
10. Нажмите кнопку **«Сохранить»**.
11. Готово. Сформируется список, в который войдут только указанные вами контрагенты.

Для отображения информации по каждому контрагенту нажмите **«Проверить список»**.
