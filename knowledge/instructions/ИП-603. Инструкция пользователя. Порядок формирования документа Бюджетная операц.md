# Описание документа «Бюджетная операция»
Документ «Бюджетная операция» используется для отражения планируемого движения денежных средств предприятия в рамках определенного сценария (раздел «Бюджетирование»).
Планирование любых данных всегда происходит для определенного сценария. Если сценариев несколько, данные по каждому из них планируются отдельно.

- Для создания необходимо открыть раздел «Бюджетирование», далее в подразделе «Планирование» на форме найти документ «Бюджетные операции» (Рисунок А1).

Рисунок А2. Список документов бюджетные операции

Рисунок А3. Создание документа
- Откроется форма заполнения документа, где необходимо заполнить поля верхней части документа и табличную часть (Рисунок А4).
Рисунок А4. Заполнение шапки документа
Основные реквизиты верхней части документа:
Номер – присваивается программой автоматически при записи документа.
Организация – выбирается из справочника Организации.
Сценарий – обязательное для заполнения поле, выбирается из справочника Сценарии бюджетирования. Данные планируются для каждого сценария отдельно (например, «План», «Факт»).  
Суммы в: – единица отображения сумм: единицы, тысячи или миллионы.
Валюта – валюта, в которой вводятся данные.
Курс – курс валюты, заполняется автоматически или вручную.
Сверх бюджета – флаг предназначен для того, чтобы провести данные по «контролируемому» сценарию «сверх бюджета», в документах, отражающих плановые данные.
Заполнять по ценам номенклатуры – указывается в случаях ведения бюджета по номенклатурам.
Основные данные табличной части документа:
- Закладка «Данные бюджета»
Период – начало периода планирования (например, первое число месяца), с учётом периодичности сценария.
Статья оборотов – статья бюджета (БДДС, БДР), по которой планируются средства.
Аналитики (ЦФО, Организация, Контрагент, Договор, Проект, Объект капиталовложений) – заполняются по необходимости.
Сумма – выделенный бюджет за определённый период.
Комментарий – текстовое примечание, которое относиться к отдельной строке табличной части.
Кнопка «Добавить» создаёт новую строку в табличной части, предназначенную для ручного ввода данных.
По кнопке «Заполнить» - «Импорт» (Рисунок А5) вызывается обработка «Форма импорта» (Рисунок А6) с помощью которой можно загрузить табличную часть из файла EXCEL.

- Закладка «Зависимые обороты»
Режим зависимых оборотов (вариант формирования зависимых оборотов по статьям оборотов) может быть автоматическим или можно установить, что зависимые обороты не будут формироваться. (Рисунок А8)
Рисунок А8. Выбор режима зависимых оборотов
Система позволяет автоматизировать расчёт плановых данных по бюджетам. Вместо ручного ввода значений вы можете задать правила (зависимости), по которым одна статья оборотов будет рассчитываться на основе другой. Это ускоряет процесс планирования и снижает риск ошибок.
- Как это работает?
Вы создаёте логическую связь между статьями в рамках сценария. Система автоматически вычисляет значение зависимой статьи, используя данные исходной.
Примеры простых зависимостей:
- Процент от суммы: статья «Комиссионные менеджерам» рассчитывается как 5% от значения статьи «Оптовые продажи».
- Фиксированный процент: статья «Возврат товаров» — 2% от «Оптовых продаж».
- Типы зависимостей
Зависимость может быть задана не только по сумме, но и по другим параметрам:
По периоду: расходы могут переноситься во времени. Пример: статья «Аренда помещений» за январь зависит от статьи «Оплата за аренду» за декабрь, так как требуется предоплата.
Многоуровневая зависимость: расчёт может происходить через промежуточную статью. Пример: статья «Затраты на доставку» зависит от «Себестоимости реализованных товаров», которая, в свою очередь, зависит от «Объёма продаж». Количество таких уровней не ограничено.
- Классическое применение: БДДС на основе БДР
Наиболее частый сценарий использования — автоматический расчёт Бюджета движения денежных средств (БДДС) на основании сформированного Бюджета доходов и расходов (БДР). При настройке этой зависимости в документе «Установка зависимых оборотов» можно указать:
- Коэффициенты НДС для корректного расчёта денежных потоков.
- Профили распределения для разнесения сумм по разным аналитикам или периодам.
- Зависимости между сценариями
Правила можно настраивать не только внутри одного сценария, но и между разными. Это позволяет создавать вариативные версии бюджета.
Например, на основе базового («Реалистичного») сценария можно автоматически сформировать «Оптимистичный» или «Пессимистичный» варианты. Для этого настраивается зависимость статей самих на себя, но с привязкой к другому, зависимому сценарию и применением соответствующих коэффициентов (например, +10% к доходам для оптимистичного варианта).
- Закладка «Дополнительно»
ЦФО, Статья оборотов и Проект на закладке «Дополнительно» (Рисунок А9) заполняются только при использовании механизма разграничения прав доступа на уровне записей (RLS). Данные поля необязательны — их можно оставить незаполненными.
Рисунок А9. Закладка «Дополнительно»
- Закладка «Комментарий»
Комментарий представляет собой текстовую заметку ко всему документу (Рисунок А10).
Рисунок А10. Пример комментария
Для того чтобы введенные данные отразились в регистрах системы, необходимо провести документ. При проведении документ формирует движения по регистру накопления «Обороты по бюджетам» (Рисунок А11).
Рисунок А11. Результат проведения документа
Если настроены маршруты согласования документа, по команде «Согласование» происходит переход в форму, в которой осуществляется визирование документа ответственными лицами компании – менеджерами, руководителями подразделений или ЦФО и т.п.
Для задания бюджетных ограничений, указанных в документе «Бюджетная операция», в рамках которых осуществляется проверка сумм в заявках на расходование средств, предназначен документ «Установка контрольных значений» (Рисунок А12). Доступ к нему имеет ограниченный круг лиц. Регламентное задание выполняет автоматическое проведение данного документа каждые 900 секунд в интервале с 09:00 до 18:00. Благодаря этому лимиты всегда актуальны с учетом всех внесённых изменений в бюджет.
Рисунок А12. Пример документа «Установка контрольных значений»
В зависимости от даты периода, установленной в табличной части документа «Бюджетная операция» в документе «Установка контрольных значений», относительно периода заполнения, в момент его проведения формируется запись на дату начала периода (01.01.2026, 01.04.2026, 01.07.2026, 01.10.2026) (Рисунок А13).

# Распределение по аналитикам и периодам
При вводе данных может возникнуть потребность распределить сумму и/или количество по аналитике, например, по ЦФО или по проектам, или по периодам, например, годовую сумму распределить по месяцам. В табличной части документа можно выполнить распределение суммы и количества по любой аналитике (кроме «Статьи оборотов»). Для этого необходимо сделать активной ячейку в колонке с аналитикой, по которой выполняем распределение (к примеру, Проект), правой кнопкой мыши вызвать контекстное меню и нажать «Распределить» (Рисунок Б1).
Рисунок Б1. Распределение по аналитикам
Далее, если необходимо будет неоднократно воспользоваться данным профилем распределения, то его можно записать в справочнике «Профили распределения», нажав кнопку «Записать». После этого следует нажать кнопку «Распределить» (Рисунок Б2).
Рисунок Б2. Обработка «Распределение бюджетных данных по профилю»
Также можно и просто выполнить единовременно распределение суммы, если в дальнейшем данный профиль использоваться не будет. Для этого сразу после заполнения в табличной части аналитик и процентов необходимо нажать кнопку «Распределить». В табличной части документа будет выполнено распределение по указанным проектам в соответствии с процентом распределения (Рисунок Б3).
Рисунок Б3. Пример распределения по аналитике договор
Для распределения годовой суммы в документе, например, по месяцам, необходимо выделить ячейку в колонке «Период», правой кнопкой мыши вызвать контекстное меню, в котором выбрать команду «Распределить». Далее, как и в случае с распределением по аналитикам, указать периоды и процент распределения, и затем нажать кнопку «Распределить».
Записанные профили распределения можно посмотреть в справочнике «Профили распределения». Их можно использовать при дальнейшей работе с документами бюджетирования, выбирая их из справочника в форме распределения.
