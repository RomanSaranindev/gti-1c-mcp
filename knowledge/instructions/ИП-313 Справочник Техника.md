# ИП-313 Справочник Техника

> Источник: `ИП-313 Справочник Техника.docx`  
> Код инструкции: `ИП-313`  
> Тип: .DOCX

---

Справочник «Техника» предназначен для хранения списка всего автотранспорта и строительной техники, используемой в организациях, их технических характеристик и другой справочной информации.
Чтобы открыть справочник техника нажмите на раздел «АТ: Автотранспорт и строительная техника» в подразделе «Работа техники» найдите наименование «Техника» (рисунок А1). Откроется форма списка справочника «Техника».
Рисунок А1. Открытие формы списка справочника «Техника»
# Формат списка
Форма списка транспортных средств позволяет организовать быстрый отбор техники по виду, наименованию, государственному номеру, инвентарному номеру, гаражному номеру и другими доступными реквизитами (рисунок Б1).
Рисунок Б1. Форма списка справочник «Техника»
Форма списка содержит пиктограммы обозначающие разные характеристики техники в таблице Б1 приведен список возможных состояний.

На форме списка можно производить отборы и добавлять собственные отборы по реквизитам, указанным в карточке техники.
# Создание новой записи в справочник
Для создания новой записи в справочник, на форме списка нажмите кнопку [Создать] (рисунок Б2).
Рисунок Б2. Создание новой записи в справочник
Откроется форма карточки техники.
## 2.1 Заполнение шапки справочника и вкладки «Основная»
Для создания записи в справочнике необходимо заполнить обязательные поля, подчеркнутые красной линией к ним, относится:
- Наименование – тип Строка: произвольное наименование техники;
- Марка, модель – выбирает из одноименного справочника. Работа со справочником описана в инструкции по ссылке.
