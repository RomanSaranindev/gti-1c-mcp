# Дополнительные настройки доступа к документам и справочникам 1С

Код инструкции: `ИП-ACL-001`
Источник: `Выгрузка Access control list из базы 1С:БИТ.ФИНАНС`
Тип: INSTRUCTION

## Описание

В системе 1С:БИТ.ФИНАНС применяются **дополнительные настройки доступа** (ACL — Access Control List) к документам и справочникам.
Они работают **поверх стандартных групповых профилей** и позволяют тонко настраивать права:
предоставлять доступ конкретным группам пользователей к определённым документам с ограничением по организации (область доступа),
а также явно запрещать отдельные действия.

Данный список показывает, какие **группы пользователей** имеют дополнительные настройки доступа
на работу с документами и справочниками сверх базового профиля.

### Обозначения прав

Перечислены только права со значением **Да** (разрешено):

| Сокращение | Полное название |
|---|---|
| Ред | Редактирование |
| Соз | Создание |
| Коп | Копирование |
| Пом | Пометка на удаление |
| Пер | Перенос в группу |
| Про | Проведение |
| Отм | Отмена проведения |
| Печ | Печать |

> **ЗАПРЕТ** — запись означает, что все права для данной группы на этот объект явно отключены.
