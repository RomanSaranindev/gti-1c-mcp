# 1. Описание документа «Корректировка контрольных значений»

Документ «Корректировка контрольных значений» (раздел «Бюджетирование») предназначен для корректировки лимитов по статьям бюджетов без внесения изменений в данные бюджетов. Например, возможно изменение лимита для оплаты за счет другой статьи бюджета, другого ЦФО или другого периода.

Создание документов «Корректировка контрольных значений», возможно как вручную, так и автоматически – из документов «Заявка на расходование денежных средств» и «Заявка на затраты» (при возникновении необходимости оплаты или расхода за счет другой статьи бюджета, ЦФО, периода и т.п.).

# 2. Создание документа «Корректировка контрольных значений» вручную и заполнение реквизитов

1. Для создания документа «Корректировка контрольных значений» вручную необходимо открыть раздел «Бюджетирование», далее в подразделе «Планирование» на форме найти документ «Корректировка контрольных значений» (Рисунок А1).

2. Откроется список документов «Корректировка контрольных значений».

3. Для создания нового документа нажимаем на кнопку [Создать] на командной панели.

4. Откроется форма заполнения документа. Необходимо выбрать *Вид контроля*:
   1. **Контроль заявок** – контроль Заявок на расходование денежных средств и Заявок на затраты по бюджетам;
   2. **Контроль бюджета** – контроль бюджета по данным другого бюджета, более верхнего уровня;
   3. **Контроль графиков договоров** – контроль графиков договоров по бюджетам.

*Сценарий* – из справочника Сценарии бюджетирования.

*Вид корректировки*:
- **Изменение** – могут вноситься любые изменения в контрольные значения бюджетов.
- **За счет** – увеличение лимита по одному набору аналитик происходит за счет уменьшения лимита по другому набору аналитик.
