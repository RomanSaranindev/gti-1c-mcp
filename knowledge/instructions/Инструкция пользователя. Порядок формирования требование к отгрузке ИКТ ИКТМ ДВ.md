# Форма списка документов «Требования к отгрузке»
Документ «Требование к отгрузке» предназначен для оформления факта передачи товарно-материально ценностей (ТМЦ) заявителю.
- Для создания документа «Требование к отгрузке» необходимо открыть раздел «Снабжение и склад», далее в подразделе «Склад» на форме найти документ «Требование к отгрузке» (Рисунок А1).
Рисунок А1. Открытие документа требование к отгрузке.
- Откроется список документов «Требования к отгрузке», где окно (форму списка) можно разделить на три части, «Командная панель», «Область отборов документов», «Список документов» (Рисунок А2).
Рисунок А2. Форма списка документов «Требования к отгрузке».
# Создание нового документа «Требование к отгрузке» и заполнение реквизитов
- Для того, чтобы создать новый документ нажимаем на кнопку [Создать] на командной панели (Рисунок Б1).
Рисунок Б1. Создание требование к отгрузке.
Откроется форма заполнения документа, где необходимо заполнить поля «Шапки» документа (Рисунок Б2).
Рисунок Б2. Заполнение «шапки» документа.
- Организация - обязательное поле заполняется из одноименного справочника;
- Склад - указать склад, с которого необходимо получить ТМЦ;
- Дата - дата документа;
- Проект – выбрать проект;
- Номенклатурная группа – заполняется на этапе согласования сотрудником Технического офиса проекта. При выборе Номенклатурной группы в шапке, то колонка в табличной части будет не видна. Так же, если не заполнять в шапке, то можно выбрать отдельно по каждой номенклатуре в табличной части. (Рисунок Б3);
Рисунок Б3. Пример заполнения Номенклатурной группы.
- Приоритет - приоритет заявки имеет два статуса «Текущий» и «Срочный». «Текущий» отрабатывается в течении трех дней, «Срочный» в течении одного дня;
- Желаемая дата - желаемая дата получения ТМЦ. При установке приоритета «Текущий», автоматически к «Желаемой дате» добавится два дня, но можно установить любую другую дату;
- Руководитель подразделения затрат – заполняется по необходимости. Поле необходимо заполнять для согласования с непосредственным руководителем заявителя. Если заявитель ТМЦ является руководителем, поле заполнять не требуется;
- Кладовщик – заполняется заведующим складом, после успешного согласования заявки. Служит для назначения кладовщика ответственного за отгрузку со склада;
- Вид операции – выбирается «на затраты», если внутренне списание, если «передача подрядчику», то открываются дополнительные поля для выбора «Контрагент» и «Договор контрагента».
- Создание нового документа на основании «Заявки на МПЗ/Приходный ордер»
Для создания «Требования к отгрузке» на основании Заявок на МПЗ, в первую очередь необходимо открыть нужный документ и проверить «Доп статус» (Рисунок Б1.1)
Рисунок Б1.1. Проверка дополнительного статуса заявки
Если «Доп статус» документа соответствует значениям «Поставлено» или «Частично поставлено», то на основе этого документа можно создать «Требование к отгрузке» (Рисунок Б1.2)
Рисунок Б1.2. Пример создания документа на основании «Заявка на МПЗ»
Рисунок Б1.2.2. Пример создания документа на основании «Приходный ордер»
При создании «Требование к отгрузке» на основании другого документа (Заявка на МПЗ, Приходный ордер), в табличной части автоматически заполняется МПЗ. (смотрите 3 пункт)
# Добавление МПЗ в табличную часть документа
Для подбора МПЗ необходимо нажать кнопку [Подбор МПЗ] (рисунок В1), откроется окно подбора МПЗ (Рисунок В2).
Рисунок В1. Подбор МПЗ.
Рисунок В2. Окно подбора МПЗ.
- ОБЛАСТЬ ОТБОРОВ. При заполнении поля «Заявка на МПЗ», отобразится только та номенклатура, которая указана в выбранной заявке на МПЗ. Для корректного подбора материалов всегда устанавливаться галочку «С учетом резервов». Поле «Поиск» позволяет искать номенклатуру в справочнике.
- ГРУППЫ ЭЛЕМЕНТОВ НОМЕНКЛАТУРЫ. Если установлен флаг «Показывать по иерархии», то в левой рабочей области отображается номенклатура из выбранной справа группы. Если флаг не установлен – отображаются все элементы справочника «Номенклатура»;
- ЭЛЕМЕНТЫ СПРАВОЧНИКА «НОМЕНКЛАТУРА», которые входят в группу, выделенную справа, либо все элементы справочника, если флаг «Показывать по иерархии» не установлен. Порядок отображения данных в описываемой области определяется кнопками отображать остатки: Все / В наличии / Доступно.
- ПОДОБРАННЫЕ ЭЛЕМЕНТЫ, отобранные пользователем для переноса в документ (может быть скрыт по кнопке «Скрыть подобранные»). Если область не отображается, необходимо нажать кнопку «Отображать подобранные».
- ПОЛЕ «ИСПОЛЬЗОВАТЬ ЯЧЕЙКИ», данное поле активно, только если для склада используется хранение по ячейкам.
- После поиска нужной номенклатуры, нажмите на неё два раза, откроется окно ввода количества (рисунок В3).
Рисунок В3. Форма подбора количества.
- ! Если по складу используется хранение по ячейкам, то форма подбора будет отличаться от рисунка (B3), пример подбора по ячейкам предоставлен ниже (рисунок В4).
- Рисунок В4. Пример подбора по ячейкам
Для подбора необходимого количества из ячейки необходимо заполнить поле «Выбор кол-ва» на форме подбора. Обратите внимание, что одна позиция ТМЦ может хранится в разных ячейках, уточните у сотрудников склада с какой ячейки можно получить ТМЦ. После подбора ТМЦ нажимаем кнопку «Перенести в форму подбора», программа вернет Вас в форму подбора ТМЦ (рисунок В2).
- После подбора МПЗ, нажимаем кнопку перенести в документ (Рисунок В5). Выбранная номенклатура перенесется в документ.
Рисунок В5. Перенос выбранной номенклатуры в документ.
# Подвал документа
Заказчик – Получатель ТМЦ со склада (Рисунок Г1).
Ответственный – заполняется автоматически автором документа.
Комментарий – комментарий к требованию.
Рисунок Г1. Пример заполнения подвала документа
После заполнения основных полей, необходимо записать документ, для этого нажмите на кнопку [Записать] на командной панели (Рисунок Г2).
Рисунок Г2. Запись документа.
# Задачи документа и маршруты согласования
Если поле «Руководитель подразделения затрат» заполнено, тогда при записи указанному руководителю придет задача на согласование заявки. По окончанию согласования «Ответственному» на почту придет уведомление о результате. Проверить состояние по задаче можно из документа, нажав на ссылку «Задачи» в верхней части документа (Рисунок Д1).
Рисунок Д1. Просмотр задачи автором требования к отгрузке.
После того как придет уведомление что требование согласовано, документ необходимо «Провести» (Рисунок Д2). Статус заявки перейдет на «На согласование».
Рисунок Д2. Проведение документа.
Далее заявка отправляется по маршруту согласования с Техническим офисом проекта и заведующим складом. Проверить состояние статуса «Требования к отгрузке» можно нажав на статус (Рисунок Д3).
Рисунок Д3. Статус документа.
Появится окно, в котором можно увидеть все состояния, в которых находилась данная заявка (Рисунок Д4).
Рисунок Д4. История изменений статусов документа.
Виды статуса документа «Требование к отгрузке»
- Черновик – создание и редактирование.
- На согласовании – документ находится на одном из этапов согласования.
- Утверждён – документ согласован всеми участниками маршрута.
- Исполнен/частично исполнен – ТМЦ выдали со склада (Расходный ордер проведен)
- Порядок действий Руководителем подразделения затрат
На стартовой странице «Начальная страница» руководителю подразделения затрат появляется задача для согласования (Рисунок Е1).
Рисунок Е1. Задача на согласование у руководителя подразделения затрат.
В задаче нужно перейти по ссылке в поле «Предмет» и посмотреть какие МПЗ указаны в Требовании к отгрузке. После в поле результат написать текст и затем нажать на кнопку (Рисунок Е2):
- [Выполнено], если согласование завершено успешно.
- [Отменить], если требуется отмена по причине отклонения.
Рисунок Е2. Задача на Руководителя подразделения.
- Порядок действий по согласованию Техническим офисом проекта и Заведующим складом.
Инициирование визирования. Как только документ «Требование к отгрузке» станет проведен, то нужно поставить визирование к данному документу.
- Сотрудник Технического офиса и Заведующий складом заходит в раздел «Рабочее место визирования» (Рисунок Ж1)
- Доступ к рабочему месту визирования: Снабжение и склад → Сервис → Рабочее место визирования.
Рисунок Ж1. Доступ к рабочему месту визирования
При открытии Рабочего места визирования выведется список документов, требующих визирования (Рисунок Ж2).
- Рисунок Ж2. Открытый список Рабочего места визирования.
- Нужно открыть документ «Требование к отгрузке» из списка двойным нажатием на соответствующую строку (Рисунок Ж3).
- Сотруднику за ролью «Технический офис проекта» нужно проставить Номенклатурную группу (IB-код) и нажать кнопку [Записать].
- Сотруднику за ролью «Заведующий складом» нужно назначить сотрудника склада ответственного за выдачу ТМЦ.
Рисунок Ж3. Обязательные поля для заполнения
Далее переходим во вкладку «Согласование» и нажимаем кнопку [Согласовано] (Рисунок Ж4)
Рисунок Ж4. Согласование.
- Далее статус документа «Требование к отгрузке» устанавливается на «Утвержден»
