# Форма списка документов «Заправочная ведомость»
Документ «Заправочная ведомость (Перемещение МПЗ между складами)» предназначен для оформления факта заправки техники на базе/объекте «собственным» топливом, и может быть создан через документ «Путевой лист» на закладке «ГСМ». Второй способ создания документа – в журнале «Заправки техники» по кнопке [Создать]. Рассмотрим порядок заполнения документа из журнала «Заправки техники».
- Для создания документа «Заправочная ведомость» необходимо открыть раздел «АТ: Автотранспорт и строительная техника», далее в подразделе «ГСМ» на форме найти документ «Заправочная ведомость» (Рисунок А1).
Рисунок А1. Открытие документа заправочная ведомость.
- Откроется список документов «Заправочная ведомость», где визуально окно (форму списка) можно разделить на три части, «Командная панель», «Область отборов документов», «Список документов» (Рисунок А2).
Рисунок А2. Форма списка документов «Заправочные ведомости».
# Создание нового документа «Заправочная ведомость» и заполнение его реквизитов
- Для того, чтобы создать новый документ нажимаем на кнопку [Создать] на командной панели (Рисунок Б1).
Рисунок Б1. Создание заправочной ведомости.
- Откроется форма заполнения документа, где необходимо заполнить поля «Шапки» документа.
– Дата – дата заправки. Дата и время заправки влияет на отображение заправки в документе «Путевой лист».
– Организация – обязательное поле заполняется из одноименного справочника (Рисунок Б2).
Рисунок Б2. Заполнение организации и даты документа.
– Склад отправитель – заполняется тот склад, с которого будет перемещено топливо. Для заполнения поля нажмите на стрелочку поля «Склад отправитель» (рисунок Б3), далее из выпадающего списка перейдите по синей ссылке «Показать все», выберете склад, с которого необходимо списать топливо.
Рисунок Б3. Выбор склада.
– Вид операции - заполним значением «Заправочная ведомость» (Рисунок Б4).
– Проект - заполним из справочника «Проекты» (Рисунок Б4).
– Бух. учет - устанавливаем обязательно, если необходимо отразить операцию бухгалтерскому учету (Рисунок Б4).
! Установку флажка «из бака в бак» НЕ устанавливать.
Рисунок Б4. Выбор вида операции и проекта.
- После заполнения основных полей, необходимо записать документ, для этого нажмите на кнопку [Записать] на командной панели (Рисунок Б5).
Рисунок Б5. Запись документа.
# Добавление списка техники в табличную часть документа
Заполнить табличную часть документа можно тремя способами: по проекту, из файла Excel, вручную через кнопку [Добавить]. Ниже описан порядок заполнения этими способами.
## 3.1 Заполнение по проекту
- Для того, чтобы заполнить табличную часть по проекту в командной панели табличной части документа (Рисунок Б6), необходимо нажать на команду «Ввести данные», где из выпадающего списка выбрать первый пункт «Заполнить по проекту».
- ! Для корректного заполнения поле «Проект» должно быть заполнено.
- Рисунок Б6. Заполнение табличной части документа по проекту.
- По нажатию кнопки «Заполнить по проекту» откроется форма (Рисунок Б7), где необходимо заполнить единственный реквизит «Топливо». После выбора вида топлива нажмите [Выполнить] (Рисунок Б7).
Рисунок Б7. Заполнение вида топлива для заполнения табличной части документа.
Программа автоматически заполнит табличную часть документа техникой, закреплённой за выбранным проектом (Рисунок Б8), а так же заполнит реквизит «Шапки» документа «Топливо», тем топливом которое выбрали на предыдущем шаге.
! Если появляется сообщение например: «Техника "Автомобильный кран г/п 350 тонн Х157КО797" находится на складе или выведена из эксплуатации.», то такую технику не удастся заправить. Обратитесь к отвественному лицу за ведении техники в программе.
Рисунок Б8. Пример заполненной табличной части документа.
## Заполнение табличной части из Excel
- В командной панели в табличной части «МПЗ» выбрать команду «Импорт» (рисунок Б9).
Рисунок Б9. Открытие формы импорта из Excel
- После выбора этой команды откроется Форма импорта. Нижняя часть формы содержит табличный документ, в который необходимо вставить информацию из файла Excel (Рисунок Б10).
Рисунок Б10. Форма для заполнения
- Из файла Excel необходимо выбрать область из 3 колонок и скопировать ее в буфер обмена (Ctrl + C):
- – Наименование техники;
- – Гаражный номер;
- Количество топлива (с датой, соответствующей дате документа «Заправочная ведомость» (Рисунок Б11).
- Рисунок Б11. Пример таблицы источника для заполнения из Excel.
- Вставить из  буфера ( Ctrl + V) в форму (Рисунок Б12).
- Рисунок Б12. Вставка данных из Excel.
- Нажимаем команду [Распознать]. По верхней табличной части заполнится таблица в нижней части формы. Проверить ее заполнение. По гаражному номеру будет заполнена техника (Рисунок Б13).
- Выполнить  команду [Загрузить].
Рисунок Б13. Распознавание табличной части документа.
- Табличная часть из формы импорта будет перенесена в таб.часть документа (Рисунок Б14).
- Записать документ.
Рисунок Б14. Пример заполненной табличной части после импорта.
## 3.3 Ручное создание записей в табличной части
Технику в табличную часть можно заполнить через кнопку [Добавить] на командной панели табличной части (Рисунок Б15). В конец табличной части добавится строка, где из справочника техника необходимо подобрать необходимую технику. Поля «Гаражный номер», «Номеклатура» заполнятся автоматически из справочника «Техника».
Рисунок Б15. Заполнение табличной части вручную.
# Заполнение «подвала» документа
В «Подвале» документа заполним поле ФИО кладовщика, осуществляющего заправку техники (Рисунок В1). При необходимости можно заполнить поле комментарий.
Рисунок В1. Заполенение отвественного кладовщика.
- Сохраняем документ. Нажимаем на кнопку «Записать» (Рисунок Б5).
# Печать документа
- Для печати документа «Заправочная ведомость» нажимаем на кнопку «Печать», где из выпадающего списка выбираем пункт «Заправочная ведомость» (Рисунок Г1).
Рисунок Г1. Выбор макета печатной формы заправочная ведомость.
- Откроется сформированный макет печатной формы, нажимаем кнопку «Печать» (Рисунок Г2).
Рисунок Г2. Печать заправочной ведомости.
# Заполнение Заправочной ведомости
- «Кладовщик» заполняет данные (Количество, ФИО Водителя, Подпись водителя) в распечатанном бланке Заправочной ведомости (Рисунок Д1).
Рисунок Д1. Заполняемые поля «Кладовщиком».
- В конце рабочего дня, после проведения заправок, данные с бланка заправочной ведомости, кладовщик переносит в созданный документ в программе 1С.БИТ (Рисунок Д2) – заполнят колонку «Количество».
- ! Если в документе присутствует техника по которой заправки не производились, необходимо удалить эти строки встав на ненужную технику и нажав клавишу «Delete» на клавиатуре.
- ! Проверьте корректность заполнения табличной части документа. Колонка «К.» (коэффициент) должно стоять значение «1», иначе данная заправка не отразится в документе «Путевой лист».
Рисунок Д2. Заполнение поле «Количество» в документе заправка в программе.
# Прикрепление файлов к документу
- Сканируем заправочную ведомость и прикрепляем к созданному документу заправочную ведомость. Нажимаем на иконку «Присоединенные файлы» (Рисунок Е1).
Рисунок Е1. Присоединение файлов к документу.
- Проводим наш документ по кнопке [Провести] на командной панели (Рисунок Е2).
Рисунок Е2. Проведение документа.
Внизу документа появится сообщение, пример: «Создан/проведен документ Перемещение товаров, материалов 00БС-018813 от 28.05.2024 23:59:59» — это означает что в бухгалтерской части программы (далее БУ) создался и провелся документ Перемещение товаров, материалов.
# Внесение изменение в документ «Заправочная ведомость»
- В случае если в документ «Заправочная ведомость» внесли изменения в табличную часть (изменилось количество заправок), то необходимо отразить эту операции и по БУ. Для отражения операции по бухгалтерскому учету необходимо в командной панели нажать кнопку «УУ -> БУ Создать» (Рисунок Ж1).  После этого бухгалтерский документ будет обновлен.
Рисунок Ж1. Создание документа по БУ.
