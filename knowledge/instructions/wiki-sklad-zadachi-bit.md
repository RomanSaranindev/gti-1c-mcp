# 1. СОЗДАНИЕ ЗАДАЧИ

1.1 Задачи в 1С.БИТ могут создаваться 2 способами:

- **вручную** Инициаторами (контролерами исполнения поставленной задачи), в т.ч. на основании уже заведенного 1С.БИТ документа;
- **автоматически** по настроенным в 1С.БИТ условиям.

1.2 Для создания Задачи **на основании уже созданного документа** необходимо перейти в раздел «Задачи» соответствующего документа (Рисунок 1).

1.2.1 В отрывшемся окне нажать «Создать» и в появившейся форме заполнить поля (Рисунок 2):

- **Срок исполнения** – установить срок исполнения Задачи.
- **Задача (кратко)** – указать краткое описание поставленной Задачи.
- **Описание** – при необходимости указать расширенное описание Задачи.
- **Предмет** – заполнится автоматически ссылкой на документ, на основании которого создается Задача.
- **Адресовать** – выбрать «Исполнителю» (если необходимо поставить задачу конкретному исполнителю), либо «Роли».
- **Исполнитель** – указать ФИО, кто по Задаче будет Исполнителем.
- Вложить документы (при необходимости), нажав на «скрепку».
- Нажать **«Создать задачу»**.

1.3 Для создания независимой Задачи Инициатор должен перейти на Начальную страницу 1С.БИТ (Рисунок 3), открыть вкладку «Исходящие» и нажать «Создать».

1.3.1 После чего в отрывшейся форме заполнить поля (Рисунок 4):

- **Срок исполнения** – установить срок исполнения Задачи.
- **Задача (кратко)** – указать краткое описание поставленной Задачи.
- **Описание** – при необходимости указать расширенное описание Задачи.
- **Предмет** – оставить поле пустым. Но при необходимости, можно указать ссылку на уже созданный документ, и тогда данная Задача появится в соответствующем документе в разделе «Задачи».
- **Адресовать** – выбрать «Исполнителю».
- **Исполнитель** – указать исполнителя.
