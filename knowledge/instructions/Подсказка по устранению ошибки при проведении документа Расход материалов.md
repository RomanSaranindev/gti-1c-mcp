# Подсказка по устранению ошибки при проведении документа Расход материалов

> Источник: `Подсказка по устранению ошибки при проведении документа Расход материалов.pdf`  
> Код инструкции: `подсказка по устранению ошибки при проведении документа расход материалов`  
> Тип: .PDF

---

Самая частая ошибка, которая возникает при проведении документа: 
 
 
Основной отчёт, с помощью которого можно устранить ошибку: 
Раздел «Склад» - «Остатки товаров». 
1. Необходимо указать в поле «На дату» текущую дату и выбрать организацию. 
 
 
2. Нажать кнопку «Показать настройки».  
 
 
3. На вкладке «Группировка» отметить галочкой поля: «Склад», «Подразделение», 
«Счёт.код счёта», «Номенклатура». При отсутствии какого-либо из полей добавить 
его через кнопку «Добавить». 
 
 
 
 
 
 


4. На вкладке «Отбор» выбрать номенклатуру и склад, вставить их значения и нажать 
«Сформировать».  
 
 
5. Результат отчёта сравнить с данными, указанными в документе «Расход материалов». 
Если в отчёте указано подразделение, то в документе «Расход материалов» обязательно 
проставляем то же подразделение в поле «Подразделение».  
Также необходимо сравнить код счета учета из отчета со значением в колонке «Счёт учёта» 
табличной части на вкладке «Материалы». Если они различаются, то исправить на тот счёт учета, 
который указан в отчёте.  
Теперь документ будет проведён без ошибок.
