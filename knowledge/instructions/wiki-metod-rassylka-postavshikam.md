# Рассылка поставщикам «Запроса предложений на закупку»

Код инструкции: ``
Источник: `wiki.hg.loc/spaces/1C`
Раздел: Методические материалы

---

**1. Открываем документ**

Запрос предложений на закупку (Снабжение и склад – Запросы предложений на закупку) – вкладка «Рассылка предложений».

**2. Заполняем ТЧ «Рассылка предложений».**

Табличную часть можно заполнить двумя способами:
- По кнопке «Заполнить таблицу поставщиками»
- Вручную по кнопке «Добавить»

Варианты ручного заполнения:
- Если поставщик есть в базе: Добавляем контрагента, контактное лицо, почта добавится автоматически, если она заведена в базу.
- Если поставщика нет в базе: Заполняем почту, в поле комментарий пишем название поставщика и данные контактного лица.
- Если поставщик есть в базе, но нет контактного лица или почты: добавляем контактное лицо, прописываем ему почту и устанавливаем флаг «Является ответственным за закупку».

**3. Проверка ТЧ «Рассылка предложений» (необязательный пункт)**

Нажимаем кнопку «Проверить возможность рассылки».

**4. Открытие формы настроек рассылки**

Нажимаем кнопку «Отправить предложение поставщикам».

**5. Настройка рассылки**

На данной странице требуется проверить текст письма и прикрепленный файл на корректность. Текст письма можно отредактировать прямо на форме настройки. Файл рассылки не корректируется.

**6. Отправка**

После проверки отправляемых данных нажимаем кнопку «Отправить».

**7. Готово!**

Рассылка направлена всем поставщикам из ТЧ «Рассылка предложений» и ответственному за документ.

---

**Действия кнопок ТЧ «Рассылка предложений»:**

- **Заполнить таблицу поставщиками** – заполняет таблицу контактными лицами поставщиков, которые ранее успешно поставляли номенклатуру из ТЧ «Состав запроса». На контактном лице поставщика обязательно должна быть установлена галочка «Является ответственным за закупку».
- **Проверить возможность рассылки** – проверяет на заполнение ТЧ «Рассылка предложений».
