# Форма списка документов «Комплектация техники»
Документ «Комплектация техники» предназначен для закрепления за техникой доп. оборудования, прицепов и т.п.
Примечание. Данные о закрепленном доп. оборудовании автоматически попадают в документ «Путевой лист» при выборе техники, на которую оформлено закрепление.
- Для создания документа «Комплектация техники» необходимо открыть раздел «АТ: Автотранспорт и строительная техника», далее в подразделе «Работа техники» на форме найти документ «Комплектация техники» (Рисунок А1).
Рисунок А1. Открытие документа комплектация техники.
- Откроется список документов «Комплектация техники», где окно (форму списка) можно разделить на три части, «Командная панель», «Область отборов документов», «Список документов» (Рисунок А2).
Рисунок А2. Форма списка документов «Комплектация техники».
# Создание нового документа «Комплектация техники»
 и заполнение реквизитов
- Для того, чтобы создать новый документ нажимаем на кнопку [Создать] на командной панели (Рисунок Б1).
Рисунок Б1. Создание комплектация техники
- Откроется форма заполнения документа, где необходимо заполнить поля «Шапки» документа.
Рисунок Б2. Заполнение «шапки» документа.
В форме документа Комплектация техники заполняются следующие реквизиты:
- Организация – организация, учет техники которой ведется в информационной базе, обязательное поле, заполняется из одноименного справочника доступных организаций; (Рисунок Б2)
- Техника – выбранная техника, с которой буду производится операции;
- Вид операции – может принимать значения «Комплектация» и «Разукомплектация»;
- Дата – дата создания документа;
Примечание. Вид операции «Комплектация» закрепляет дополнительно оборудование за выбранной техникой. Вид операции «Разукомплектация» открепляет дополнительно оборудование от выбранной техники.
- Раздел «Дополнительное оборудование» состоит из командной панели и табличной части документа (Рисунок Б3).
Рисунок Б3. Раздел «Дополнительное оборудование».
В командной панели присутствует две активные кнопки перемещения строк дополнительного оборудования, а также две активные команды «Добавить» и «Заполнить по текущему состоянию» (Рисунок Б4).
Рисунок Б4. Командная панель раздела «Дополнительное оборудование».
- Добавить – Команда добавляет новую строку в табличную часть документа для выбора дополнительного оборудования из справочника «Техника».
- Клавиши-перемещения – Кнопки для перемещения строк в табличной части документа.
- Заполнить по текущему состоянию – Команда выводит актуальный список дополнительного оборудования, закрепленный за выбранной техникой.
Примечание. При добавление дополнительного оборудования из справочника «Техника», в справочнике присутствует фильтрация по полю «Порядок использования».
В табличной части отображается выбранное дополнительно оборудование для прикрепления к технике.
# Подвал документа
- Ответственный – заполняется автоматически автором документа;
- Комментарий – используется для пометок и дополнительной информации по документу.
Рисунок В1. Пример заполнения подвала документа
# Завершение формирования документа и настройки БИТ
После заполнения основных полей и табличной части, необходимо записать документ, для этого нажмите на кнопку [Записать] на командной панели (Рисунок Г1).
Рисунок Г1. Запись документа.
По окончании заполнения и проверки документа необходимо его «Провести» (Рисунок Г2).
Рисунок Г2. Проведение документа.
Маршрутов согласования на момент ввода в эксплуатацию данной инструкции не предусмотрено.
Для проверки закрепления дополнительного оборудования к выбранной техники, необходимо провалится в карточку техники и на вкладке «Доп. Оборудование» проверить наличие актуальной записи (Рисунок Г3).
Рисунок Г3. Вкладка «Доп. Оборудование» в карточке техники.
