# Выравнивае остатков в УУ из БУ

> Источник: `Выравнивае остатков в УУ из БУ.docx`  
> Код инструкции: `выравнивае остатков в уу из бу`  
> Тип: .DOCX

---

Выравнивание остатков можно разделить на три этапа:
- Сформировать отчет, сравнивающий остатки в управленческом учете (далее УУ) и бухгалтерском учете (далее БУ);
- Создать документ «Инвентаризация МПЗ»;
- Создать на основании приходный ордер и расходный ордер по необходимости.
# Сформировать отчет
Для того чтобы сформировать отчет, сравнивающий остатки в УУ и БУ необходимо зайти в раздел «Склад и снабжение» раздел «Дополнительные отчеты» (рисунок 1).
Рисунок 1. Дополнительные отчеты
Откроется окно с дополнительными отчетами, где необходимо добавить отчет с наименованием «МПЗ УУ vs БУ», для этого нажмите на синюю ссылку внизу формы «Настроить список» (рисунок 2). Когда отчет добавим на форму, нажимаем кнопку «Выполнить» (рисунок 3), откроется отчет «МПЗ УУ vs БУ».
Рисунок 2. Добавление отчета
Рисунок 3. Запуск отчета
Заполняем обязательные параметры отчета такие как период и склад (рисунок 4). Период формирования отчета лучше установить текущую дату, поскольку мы будем создавать расходный ордер из документа «инвентаризация МПЗ» то, при проведении расходного ордера всегда сверяются остатки на текущий момент, не зависимо от установленной даты в документе расходный ордер.
Рисунок 4. Обязательные параметры отчета.
Выберем вариант отчета для выравнивая остатков. Для этого нажмем на значок «Выбор варианта отчета» (рисунок 5) и выберем версию с названием «МПЗ УУ vs БУ – выравнивание остатков ВГСП»
Рисунок 5. Выбор варианта отчета.
Сформируем отчет, нас интересует колонка «Расхождение». Она показывает разницу между УУ и БУ учетом. Если значение колонки «Расхождение» является положительным числом, то этот товар есть на складе только по УУ. Если же значение колонки «Расхождение» отрицательное число, то эта позиция есть только по данным БУ (рисунок 6).
Рисунок 6. Пример отчета с расхождением остатков УУ и БУ.
# Инвентаризация МПЗ
- Для создания документа «Инвентаризация МПЗ» необходимо в разделе «Склад и снабжение» выбрать документ «Инвентаризация МПЗ» как на рисунке 7.
Рисунок 7. Документ инвентаризация МПЗ.
Создадим документ «Инвентаризация МПЗ» нажав кнопку «Создать» в журнале документов (рисунок 8).  Если кнопки «Создать» нет на форме, то необходимо запросить права в Service Desk на создание и проведение документа «Инвентаризация МПЗ».
Рисунок 8. Создание документа «Инвентаризация МПЗ»
Заполним поля шапки документа обязательными реквизитами «Организация» и «Склад». По УУ не ведется учет в разрезе подразделений, поэтому поле «Подразделение» можно не заполнять (рисунок 9).
Рисунок 9. Пример заполнения шапки документа.
Далее заполним табличную часть документа «Инвентаризация МПЗ» по кнопке «Заполнить по остаткам». Данные заполнятся согласно нашему отбору указанного в шапке документа остатками по УУ (рисунок 10).
Рисунок 10. Пример заполнения табличной части документа
После заполнения табличной части документа номенклатурой, сверяем остатки с отчетом МПЗ УУ vs БУ, сформированным ранее. Заполняем поля по следующему принципу:
! В табличной части документа мы изменяем только колонку «Количество факт».
1) Если в отчёте колонка БУ не заполнена и остаток есть только по УУ, тогда в документе инвентаризации колонка «Количество факт» должна быть равна 0.
2) Если в отчете колонка БУ заполнена и колонка УУ тоже заполнена и между ними есть разница как на рисунке 11, тогда в колонку документа «Количество факт» ставим по данным БУ (рисунок 11).
3) Если же по УУ и БУ данные равны, тогда в документе колонку «Количество факт» оставляем без изменений.
Рисунок 11. Пример заполнения документа на основании отчета.
- Если в отчете в колонке «Расхождение» есть числа со знаком минус, это означает что данная позиция есть только БУ учету. Для выравнивая таких остатков, копируем наименование номенклатуры из отчета далее идем в документ инвентаризация и через кнопку «Добавить» в командной панели создаем новую строчку в документе. Вставляем ранее скопированную позицию и в колонке «Количество факт» устанавливаем то количество, которое указано по данным БУ в отчете (рисунок 12).

# Создание документов на основании инвентаризации МПЗ
Для выравнивания остатков необходимо на основании инвентаризации сформировать документы «Приходный ордер» и «Расходный ордер».
После того как выровняли остатки проведите документ кнопкой «Провести» в шапке документа. Далее необходимо в шапке документа нажать кнопку «Создать на основании» появится меню выбора какой документ создать на основании «Приходный ордер» или «Расходный ордер» (рисунок 13).
Рисунок 13. Создание документа на основании инвентаризации.
Создадим документ «Расходный ордер» на основании инвентаризации. Создастся документ с типом операции «На затраты», табличная часть будет заполнена из документа «Инвентаризация» (рисунок 14). До заполните реквизиты Способ отражения затрат, физ. лицо, номенклатурная группа, подразделение и «Проведите» документ «Расходный ордер». Обратите внимание что галочку «Бух. Учет» устанавливать не нужно, так же отражать этот документ по БУ не нужно. Это технический документ для выравнивания остатков по УУ.
Рисунок 14. Пример создания «Расходного ордера».
Документ «Приходный ордер» создается аналогично «Расходному ордеру», при этом вид операции будет «Излишки», основание всё тот же документ «Инвентаризация» (рисунок 15). Проведите документ «Приходный ордер». Обратите внимание что галочку «Бух. Учет» устанавливать не нужно, так же отражать этот документ по БУ не нужно. Это технический документ для выравнивания остатков по УУ.
