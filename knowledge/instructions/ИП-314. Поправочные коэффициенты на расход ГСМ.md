# ИП-314. Поправочные коэффициенты на расход ГСМ

> Источник: `ИП-314. Поправочные коэффициенты на расход ГСМ.docx`  
> Код инструкции: `ИП-314`  
> Тип: .DOCX

---

В справочнике «Поправочные коэффициенты на расход ГСМ» хранится информация обо всех условиях эксплуатации, для которых изменяется нормативный расход топлива автотранспортных средств, строительных машин и механизмов.
Для создания записи в справочнике необходимо открыть раздел «АТ: Автотранспорт и строительная техника», далее в подразделе «ГСМ» - «Нормативный расход ГСМ» на форме найти «Поправочные коэффициенты на расход ГСМ» (Рисунок 1).
Рисунок 1. Открытие документа «Поправочные коэффициенты на расход ГСМ»
Откроется список записей справочника «Поправочные коэффициенты на расход ГСМ», в котором форму списка визуально можно разделить на две части: наименование категорий поправочных коэффициентов и сам список записей (Рисунок 2).
Рисунок 2. Форма списка документов
При создании документа будут доступны для заполнения следующие реквизиты:
• Наименование – название поправочного коэффициента ГСМ;
• Родитель – группа родитель. Выбирается при необходимости отнести созданный коэффициент к определённой группе. Если осуществлять создание коэффициента уже из нужно группы, то ее наименование будет проставлено автоматически;
• Вид топлива - справочник «Номенклатура». Нормы расхода могут быть заданы для конкретного вида топлива. Вид топлива может быть не указан, в таком случае, нормы применяются на все виды топлива;
• Порядок – по умолчанию 0;
• Условия использования - справочник «Условия»;
• % надбавки к нормативному расходу топлива – Тип Число. Если число отрицательным, базовая норма будет уменьшена на заданное значение процента;
• Описание – текст описания коэффициента;
• Используется – при проставлении признака коэффициент будет учтен при расчете нормативного расхода топлива по путевому листу.
