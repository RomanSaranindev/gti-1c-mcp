# Основные характеристики документа 
«Форма ввода бюджета»
Документ «Форма ввода бюджета» (раздел «Бюджетирование) представляет собой универсальный конструктор ввода бюджета.
- Рис.А1 (Форма документа «Форма ввода бюджета»)
Структура бюджета и порядок заполнения аналитик бюджетирования (ЦФО, сценарий, проект и др.) задаются в настройках форм ввода бюджета (справочник «Настройки форм ввода бюджета»).
На закладке «Основные» формы ввода бюджета выбирается Настройка формы из справочника «Настройки форм ввода бюджета». Указывается дата начала и дата окончания планирования, валюта, в которой составляется бюджет, курс и кратность валюты. Если дата окончания планирования не указана, период планирования определяется по продолжительности, заданной в справочнике «Сценарии бюджетирования».
Бюджет может составляться в единицах, тысячах или миллионах. Нужное значение указывается в поле «Суммы в».
Режим зависимых оборотов (вариант формирования зависимых оборотов по статьям оборотов) может быть автоматическим или ручным, также можно установить, что зависимые обороты не будут формироваться.
Формирование зависимых оборотов будет рассмотрено далее, в разделе.

В поле «Значения по умолчанию» можно указать значения аналитик, которые будут автоматически подставляться в табличную часть документа при вводе данных. ЦФО, Статья оборотов и Проект заполняются также при использовании механизма разграничения прав доступа на уровне записей (RLS).
Сценарий является обязательным для заполнения разрезом бюджетирования, способ заполнения сценария может быть только «По умолчанию без возможности редактирования». По выбранному сценарию будут отражены плановые данные компании.
В поле «Отбор» отображаются условия отбора, заданные в настройке формы ввода бюджета. При необходимости можно изменять, добавлять или удалять условия отбора.
Если бюджет формируется по статьям оборотов, поддерживающих количественно-суммовой учет, то возможно использование нормы для расчета суммы по статье по формуле «Количество*Норма= Сумма».
Нормы могут вводиться в табличную часть «Данные» вручную, а могут подставляться автоматически из регистра «Значения произвольных параметров». Для автоматической подстановки норм необходимо выбрать вид произвольного параметра в поле «Параметр норм». Вид параметра выбирается из плана видов характеристик «Виды произвольных параметров» (раздел «Настройки (БИТ)»). Для включения механизма использования норм в бюджетировании, необходимо установить в Константах (БИТ) флаг «Использовать нормы в бюджетировании».
Для заполнения цен в Бюджетах продаж или закупок система позволяет использовать Цены номенклатуры, введенные документом «Установка цен номенклатуры».

# Ввод плановых данных
На закладке «Данные бюджета» вводятся планируемые обороты (доходы и расходы, поступления и выплаты) в разрезе статей, ЦФО и других аналитик бюджетирования.
При нажатии на кнопку «Обновить» будет сформирована структура бюджета в соответствии с выбранной настройкой формы ввода бюджета (по вертикали), периодичностью сценария бюджетирования и продолжительностью периода планирования (по горизонтали). Например, если в настройке указан способ заполнения для статей оборотов - «Разворачивать», то структура бюджета будет представлять собой дерево статей оборотов.
Примечание. Для того, чтобы дерево статей было заполнено в соответствии со структурой статей, заданной в справочнике «Бюджеты», необходимо в настройке формы ввода бюджета в поле «Бюджет» указать конкретный бюджет, например, БДР.
Планируемые суммы оборотов вносятся вручную в ячейки зеленого цвета. Данные бюджета могут быть автоматически заполнены по данным любого сценария бюджетирования (скопированы) (кнопка «Заполнить – Копирование данных бюджета»). Кроме того, возможно автоматическое заполнение плановых данных по произвольным источникам (кнопка «Заполнить – Получение данных бюджета») или загрузка из файла MS Excel (команда «Обмен MS Excel») и из «Форм сбора данных» (загрузка из файла Excel, предварительного выгруженного из справочника «Виды форм сбора данных» и заполненного бюджетными данными).
Примечание. При выгрузке шаблона в MS Excel необходимо учитывать следующее: если необходимо вводить собственные формулы в файле MS Excel для расчета некоторых показателей, то рекомендуется сначала выгрузить шаблон, затем скопировать его в отдельный файл, где будут настраиваться формулы, выполнить все расчеты, а затем конечные значения скопировать в выгруженный из Формы ввода бюджета шаблон. И уже этот шаблон загружать обратно в Форму ввода бюджета. Если шаблон будет содержать не значения, а формулы, написанные вручную, то загрузка может быть выполнена некорректно или не выполнена совсем.
Также данные бюджетов могут быть заполнены по данным графиков платежей и графиков начислений, сформированных в документах «Дополнительные условия по договорам». Для этого предназначена кнопка «Заполнить – Копирование данных графиков договоров».
При заполнении ячейки в табличной части «Данные» появляется строка с указанной суммой, в которой можно заполнить нужные аналитики: контрагента, договор, ЦФО и т.д. При добавлении новой строки с суммой дохода или расхода, общая сумма в ячейке формы бюджета увеличится.
Для того, чтобы в документе в группах статей оборотов итоги рассчитывались с учетом коэффициентов, заданных в справочнике «Бюджеты», в справочнике «Настройки форм ввода бюджета» нужно установить флаг «Использовать коэффициенты статей бюджета».

По команде «Присоединенные файлы» происходит переход в форму, в которой можно прикрепить к документу файлы любого формата, например, скан-копию утвержденного бюджета и т.п.
# Изменение суммы на процент или значение
В документе «Форма ввода бюджета» реализована возможность изменения суммы на процент или фиксированное значение для выделенных ячеек. Для этого необходимо в табличной части документа выделить одну или несколько ячеек и нажать на кнопку «Изменить сумму».
Рис.В1 (Форма команды изменения суммы в документе «Форма ввода бюджета»)
Далее следует в открывшейся форме указать на значение или на процент необходимо изменить сумму и нажать ОК. Если сумму необходимо увеличить, то значение или процент вводится без указания знаков, если значение необходимо уменьшить – со знаком «-».
# Распределение данных по периодам и аналитике
При вводе плановых данных может возникнуть потребность распределить суммы по аналитике, например, по ЦФО или по проектам, или по периодам, например, годовую сумму распределить по месяцам.
- Распределение по аналитике.
Для распределения суммы в документе «Форма ввода бюджета», например, по проектам, необходимо в строке табличной части «Данные» ввести сумму, которую необходимо распределить, выделить ячейку в колонке с аналитикой, по которой нужно распределить сумму, правой кнопкой мыши вызвать контекстное меню, в котором выбрать команду «Распределить» либо воспользоваться специальной командой «Распределить по аналитике».
Откроется форма, в которой можно по кнопке «Подобрать» заполнить в табличной части проекты, по которым нужно выполнить распределение суммы расходов, и указать процент распределения для каждого проекта. Если сумму необходимо распределить равномерно, то можно воспользоваться кнопкой «Равномерно».

# Использование формул для расчета показателей бюджета
При вводе плановых данных в документе «Форма ввода бюджета» могут автоматически рассчитываться различные финансовые показатели, например, рентабельность, прибыль, EBITDA, ликвидность и другие показатели.
Рис.Д1 (Табличная часть заполнения бюджета в документе «Форма ввода бюджета»)
Расчет происходит по формулам, настроенным в справочнике «Настройки форм ввода бюджета».
Примечание. Создание формул возможно только в справочнике «Настройки форм ввода бюджета» с фиксированным макетом. При использовании таких настроек в документе «Форма ввода бюджета» макет табличной части формируется в соответствии с макетом, созданном в Настройке формы ввода бюджета. # Копирование бюджета
Суммы оборотов по бюджету могут быть автоматически заполнены с помощью копирования данных из другого бюджета, например из бюджета за прошлый год. Для этого необходимо нажать кнопку «Заполнить – Копирование данных бюджета». В открывшейся форме следует указать параметры, по которым будет производиться копирование данных:
- Период, данные за который будем копировать в новый документ;
- В разделе «Отборы и параметры» можно установить отбор по аналитикам и реквизитам аналитик. Данные будут скопированы с учетом установленных отборов. Например, можно установить отбор по ЦФО, тогда в новый документ будут скопированы данные только по указанному ЦФО.
В поле «Периодичность» указывается периодичность, с которой необходимо скопировать данные из регистра. Например, данные были введены по месяцам, но копируем мы их в Форму ввода бюджета по сценарию с периодичностью Квартал, тогда можно установить Периодичность Квартал, и данные в форму обработки заполнятся уже в свернутом виде по кварталам. Если же копирование осуществляется на сценарий с Периодичностью Квартал, но в обработке требуется увидеть данные с помесячной разбивкой (так, как они были введены ранее), то нужно установить Периодичность Месяц.
Рис.Е1 (Форма команды «Копирование данных бюджета» в документе «Форма ввода бюджета»)
- В поле «Настройки» можно установить вид и значение отклонений относительно копируемых данных. Отклонения можно задать отдельно для суммы и для количества, в абсолютной величине или в процентах. Реквизит «Сдвиг дат» позволяет копировать данные бюджета со сдвигом на любой временной промежуток, кратный периодичности выбранного сценария бюджетирования (день, неделя, месяц и т.п.). Например, если указать сдвиг дат 12 месяцев, то данные бюджета за 2008 год будут скопированы в те же месяцы, только 2009 года.

Рис.Е2 (Форма справочника «Профиль распределения»)
- Флаг «Использовать значения по умолчанию» - если данный флаг установлен, то при копировании данных значения некоторых аналитик, заданных по умолчанию в документе «Форма ввода бюджета», например, ЦФО, будут заменены на значения из Формы ввода бюджета.
- Флаг «Заполнять комментарии к строкам бюджета» - если данный флаг установлен, то при копировании данных будут копироваться также комментарии к строкам бюджета.
В табличной части «Данные» по кнопке «Обновить» заполняются данные выбранного сценария с учетом периода, установленных отборов, отклонений, сдвига дат и профиля распределения по периодам. Суммы в колонке «Сумма документа» могут быть скорректированы до того, как будут перенесены в документ.
Далее флажками необходимо отметить те строки, которые должны быть скопированы, и нажать кнопку «Перенести». По кнопке «Перенести – Загрузить» данные из табличной части будут загружены в табличную часть документа «Форма ввода бюджета», при этом, если в документе уже были введены какие-либо данные, они будут заменены новыми данными. По кнопке «Перенести – Добавить» данные из табличной части будут добавлены дополнительно к данным документа «Форма ввода бюджета». По кнопке «Перенести – Заменить» данные из табличной части заменят данные документа «Форма ввода бюджета» по соответствующей статье оборотов и периоду.
# Получение данных бюджета
Суммы оборотов по бюджету могут быть автоматически получены с помощью произвольных источников. В качестве источников могут использоваться любые данные информационной базы, например, плановые или фактические данные за предыдущие периоды, данные бухгалтерского или управленческого учета.
Для получения данных бюджета используется обработка, которая вызывается по кнопке «Заполнить – Получение данных бюджета».
Рис.Ж1 (Форма команды «Получения данных бюджета» в документе «Форма ввода бюджета»)
Примечание. С помощью данной обработки можно, например, заполнить оперативный бюджет движения денежных средств на основании созданных Заявок на расходование денежных средств и Планируемых поступлений денежных средств. Для этих целей в поставку включены предопределенные источники данных (раздел «Получение данных» - «Источники данных» - папка «Получение планируемых платежей и поступлений»).
В открывшейся форме обработки следует указать источник данных, он выбирается из справочника «Источники данных».
Важно! При использовании обработки «Получение данных бюджета» в выбранном источнике данных (справочник «Источники данных») необходимо указать тип «Отчетность», так же важно, чтобы для нужного ресурса был установлен синоним СуммаСценарий. Данные по этому ресурсу будут загружены в обработку в реквизиты «Сумма (регистр)» и «Сумма». На основании Суммы будет рассчитана в обработке Сумма документа (сумма в валюте документа, в который загружаются данные). Так же необходимо, чтобы при получении данных в обработку заполнилась Статья оборотов, в противном случае не будут заполнены Сумма и Сумма документа. Период – период, данные за который будем копировать в новый документ.
На закладке «Отбор» можно установить отбор по аналитикам и реквизитам аналитик. Данные будут скопированы с учетом установленных отборов. Например, можно установить отбор по сценарию бюджетирования, тогда в новый документ будут получены данные только по указанному сценарию.
Сценарий документа – сценарий документа, на который будут записаны полученные данные.
В поле «Настройки» можно установить вид и значение отклонений относительно получаемых данных. Отклонения можно задать отдельно для суммы и для количества, в абсолютной величине или в процентах. Реквизит «Сдвиг дат» позволяет получать данные со сдвигом на любой временной промежуток, кратный периодичности выбранного сценария бюджетирования (день, неделя, месяц и т.п.). Например, если указать сдвиг дат 12 месяцев, то данные бюджета за 2008 год будут скопированы в те же месяцы, только 2009 года. В полях «Валюта сумм» и «Курс» можно указать валюту и курс получаемых с помощью источника данных.
В табличной части «Данные» по кнопке «Обновить» заполняются данные в соответствии с выбранным источником, установленными отборами, отклонениями и сдвигом дат. Суммы в колонке «Сумма документа» могут быть скорректированы до того, как будут перенесены в документ.
Далее флажками необходимо отметить те строки, которые должны быть перенесены в документ, и нажать кнопку «Перенести». По кнопке «Перенести – Загрузить» данные из табличной части будут загружены в табличную часть документа «Форма ввода бюджета», при этом, если в документе уже были введены какие-либо данные, они будут заменены новыми данными. По кнопке «Перенести – Добавить» данные из табличной части будут добавлены дополнительно к данным документа «Форма ввода бюджета». По кнопке «Перенести – Заменить» данные из табличной части заменят данные документа «Форма ввода бюджета» по соответствующей статье оборотов и периоду.
# Копирование данных графиков договоров
Суммы оборотов по бюджету могут быть автоматически заполнены с помощью копирования данных из графиков договоров, введенных в документы «Дополнительные условия по договорам». Для этого необходимо нажать кнопку «Заполнить – Копирование данных графиков договоров».
Рис.З1 (Форма команды «Копирование данных графиков договоров» в документе «Форма ввода бюджета»)
В открывшейся форме следует указать параметры, по которым будет производиться копирование данных:
- Период, данные за который будем копировать в новый документ;
- В разделе «Отборы и параметры» можно установить отбор по аналитикам и реквизитам аналитик. Данные будут скопированы с учетом установленных отборов. Например, можно установить отбор по ЦФО, тогда в новый документ будут скопированы данные только по указанному ЦФО.
- В поле «Периодичность» указывается периодичность, с которой необходимо скопировать данные из регистра. Например, данные были введены по месяцам, но копируем мы их в Форму ввода бюджета по сценарию с периодичностью=Квартал, тогда можно установить Периодичность= Квартал, и данные в форму обработки заполнятся уже в свернутом виде по кварталам. Если же копирование осуществляется на сценарий с Периодичностью=Квартал, но в обработке требуется увидеть данные с помесячной разбивкой (так, как они были введены ранее), то нужно установить Периодичность=Месяц.
- В поле «Настройки» можно установить вид и значение отклонений относительно копируемых данных. Отклонения можно задать отдельно для суммы и для количества, в абсолютной величине или в процентах. Реквизит «Сдвиг дат» позволяет копировать данные бюджета со сдвигом на любой временной промежуток, кратный периодичности выбранного сценария бюджетирования (день, неделя, месяц и т.п.). Например, если указать сдвиг дат 12 месяцев, то данные бюджета за 2008 год будут скопированы в те же месяцы, только 2009 года.
- В поле «Валюта» указывается валюта, в которой были введены копируемые данные. То есть, если копируем данные, введенные в USD, то необходимо поставить валюту USD, если копируем данные в рублях, то указываем валюту RUB. При этом сценарий, на который копируются данные, может быть, в любой валюте, валюта документа так же может быть любой, при загрузке данных в документ данные пересчитаются в валюту документа. Если данные вводились в разных валютах, то копирование нужно производить поочередно. Сначала, например, можно установить в обработке валюту USD и отбор по валюте USD, выполнить копирование данных. Затем установить отбор по валюте RUB и валюту в обработке RUB, и выполнить копирование в рублях.
- Также в поле «Настройки» можно указать Профиль распределения по периодам для целей распределения копируемых данных по разным периодам времени. Например, при копировании квартального бюджета можно распределить квартальную сумму по месяцам, указав соответствующие проценты распределения для каждого месяца. Периодичность сдвига дат необходимо установить равной «месяц». Для равномерного распределения копируемых квартальных данных (сценарий с периодичностью «Квартал») по месяцам (сценарий с периодичностью «Месяц»), профиль распределения должен быть настроен следующим образом:
