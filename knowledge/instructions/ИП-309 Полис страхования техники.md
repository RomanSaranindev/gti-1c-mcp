1. Документ «Полис страхования техники» 
 
Документом «Полис страхования техники» ведется учет страхования техники (рис. 
1). Его оформление включает в себя отражение расходов на оплату страховых премий и 
их последующее распределение на затраты, а также учет страхового возмещения.

Рисунок 3. Заполнение документа. 
 
 
В шапке документа «Полис страхования техники» заполняются следующие 
реквизиты документа (см. рис. 3): 
 
• Организация – организация, учет деятельности которой ведется в информационной 
базе, обязательное поле, заполняется из одноименного справочника доступных 
организаций; 
• Дата – указывается дата заведения данного полиса в систему 1С БИТ, заполняется 
автоматически при записи документа; 
• Вид страхования – в данном поле указывается вид страхования, заполняется из 
одноименного справочника доступных видов. 
• Техника – транспортное средство. Выбирается из справочника транспортных средств;

• Договор контрагента – в данное поле подставляется договор с контрагентом, путем 
выбора из справочника доступных договоров (договора выгружаются автоматически из

Рисунок 3.1. Выбор договора. 
 
 
В форме данных полиса заполняются следующие данные документа (см. рис. 3): 
 
• Страховщик – организация, выполняющая страхование. Выбирается из справочника 
контрагенты, обязательное поле для заполнения; 
• Выгодоприобретатель – застрахованная организация. Выбирается из справочника 
контрагенты, обязательное поле для заполнения. Данное поле может быть заполнено 
автоматически после подбора договора; 
• Номер полиса – номер страхового документа. Обязательное поле для заполнения. 
Данное поле может быть заполнено автоматически после подбора договора 
• № доп. Соглашения – номер дополнительно документа к основному договору. Данное 
поле не обязательно для заполнения. 
• Период – указывается дата начала действия договора и конец; 
• Страховая сумма – максимальная сумма выплаты от страховщика 
• Сумма вознаграждения – стоимость страховки 
• Франшиза - это сумма ущерба, которую страхователь оплачивает самостоятельно при 
наступлении страхового случая. 
• Тип франшизы – доступны для выбора два типа: 
Безусловная франшиза — это фиксированная сумма, которая вычитается из каждой 
страховой выплаты.  
Условная франшиза - если ущерб меньше установленной суммы, страховая компания 
ничего не выплачивает, но, если ущерб превышает эту сумму, выплачивается вся 
сумма ущерба без вычета.
