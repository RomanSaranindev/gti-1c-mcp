# Приходный ордер с видом операции «От поставщика»
- Для создания Приходного ордера на основании документа «Заказа поставщику» пользователь должен в 1С.БИТ перейти в блок «Снабжение и склад», далее в разделе «Склад» выбрать «Приемка» (Рисунок А1).
- Рисунок А1. Обработка «Приемка» для приемки МПЗ.
- В открывшемся рабочем месте «Приемка» необходимо заполнить область отборов чтобы найти не оприходованные заказы поставщику и на их основании создать «Приходный ордер». Доступные поля формы отборов:
- Организация - выбрать организацию получателя МПЗ указанный в документе УПД. При заполнении поля на список заказов будет наложен отбор по указанной организации.
- Контрагент - заполнить поставщика МПЗ указанный в УПД. При заполнении поля на список заказов будет наложен отбор по указанному контрагенту.
- Проект - При заполнении поля в списке заказов поставщику будут те заказы, у которых заполнено поле проект (Рисунок А2).
Рисунок А2. Список заказов поставщику.
- В списке документов заказов поставщику встаньте на строку чтобы увидеть список МПЗ по выбранному заказу, МПЗ отразятся в нижней табличной части. Если Вы нашли нужный заказ, нажмите кнопку [Создать приходный ордер] (Рисунок А3).
- Рисунок А3. Создание документа «Приходный ордер».
- В открывшемся документе приходный ордер все реквизиты заполнятся автоматически по документу «Заказ поставщику». Необходимо проверить реквизиты шапки документа, заполнить реквизит «Склад», в табличной части МПЗ, проверить суммы, «ставки НДС», «Количество», «Номенклатуру», «Единицы измерения». Если по факту ТМЦ пришло больше, чем в документе «Заказ поставщику», тогда колонка «Толеранс» покажет отклонения по приходу. (Рисунок А3).
- Рисунок А3. Толеранс по документу.
- Установить признак «Бух. учет» (Рисунок А4).
- Рисунок А4. Признак бух учет.
- Нажать на кнопку «Провести». Документ сохранится.
- Далее по документу «Приходный ордер» необходимо создать документ бухгалтерскому учету нажав на зеленую галочку (Рисунок А5). Появится сообщение что создан документ «Создан документ Поступление (акт, накладная, УПД) «Номер» от «дата»» (Рисунок А6).
- Рисунок А5. Создание ПТУ на основании приходного ордера.
- Рисунок А6. Сообщение об успешном создании УПД.
- Для перехода к документу «Поступление (акт, накладная, УПД)» нажать на кнопку с голубой стрелкой (Рисунок А7).
- Рисунок А7. Переход в УПД из приходного ордера.

# Приходный ордер с видом операции «От подотчетника»
- При формировании документа приходный ордер с видом операции «От подотчетника» для заполнения необходимо заполнить следующие поля (рисунок Б1):
- – Организация - организация, по которой необходимо провести приходный ордер.
- – Вид операции - выбрать вид операции от «От подотчетника».
- – Физ. лицо - выбрать физическое лицо, которое ответственно за сдачу авансового отчета.
- – Склад - указать склад, на который будет сделано поступление товаров указанный в табличной части документа.
- – Подразделение – указать подразделение.
- – Бух. учет. – обязательно для установки, чтобы на основании приходного ордера создался документ «Авансовый отчет».
- Рисунок Б1. Пример заполнения шапки документа с видом операции «От подотчетника».
- Для заполнения табличной части (МПЗ) документа приходный ордер необходимо нажать кнопку [Добавить] для добавления номенклатуры в табличную часть (Рисунок Б2).
- После нажатия кнопки [Добавить], необходимо заполнить следующие поля:
- Номенклатура - заполнить номенклатуру согласно представленному авансовому отчету подотчетного лица.
- Ед. изм. - единица измерения заполнится автоматически из справочника автоматически из справочника «Номенклатура».
- К. - коэффициент всегда заполняется автоматически. Равен значению 1.
- Цена - цена приобретения ТМЦ.
- Количество - количество ТМЦ согласно авансовому отчету.
- Сумма – заполнится автоматически по формуле [Количество * Цена].
- Сумма НДС – если ТМЦ включает НДС, то необходимо выбрать ставку НДС и формы выбора. Если ТМЦ не включает НДС, то позиция не заполняется.
- Рисунок Б2. Пример заполнения табличной части приходного ордера.
- После заполнения, документ необходимо провести (Рисунок Б3). Далее для отражения документа по бухгалтерскому учету необходимо нажать кнопку создания авансового отчета (Рисунок Б4). Появится сообщение что документ был создан (Рисунок Б5).

# 1.4 Приходный ордер с видом операции «Возврат от подрядчика»
Возврат подрядчиком неиспользованных материалов, переданных ему ранее как давальческие МПЗ в переработку, оформляется в программе приходным ордером: возврат от подрядчика (Рисунок В1).
Рисунок В1. Возврат от подрядчика
При выборе данного вида операции пользователю необходимо заполнить следующие реквизиты:
– Контрагент - организация (подрядчик), которой передавались давальческие материалы в переработку;
– Договор контрагента;
– Склад - склад, на который будет оприходован материал от подрядчика.
Этот же вид операции используется, когда необходимо отразить в программе факт оприходования на склад продукции, полученной из переработки.
Документ может быть создан на основании отчета подрядчика об использовании МПЗ. Склад, на который будет оприходована продукция, устанавливается автоматически из реквизита «Склад продукции (спр.)».
Документ передачи в данном случае будет - «Отчет подрядчика об использовании МПЗ» (Рисунок В2).
Рисунок В2. Отчет подрядчика об использовании давальческого сырья.
Документ не предназначен для передачи в Б У. При попытке установить флаг «Бух.учет» и проведении документа будет сформировано сообщение: «В документе возвращается от подрядчика продукция. Данный документ не отражается в БУ!» (Рисунок В3).
Рисунок В3. Запрет на отражение в БУ.
# 1.5 Приходный ордер с видом операции «Излишки»
Приходным ордером с видом «Излишки» производится корректировка учетных данных в системе по количеству и стоимости материалов, когда в результате инвентаризации выявлены материалы, не числящиеся в учете.
! Не рекомендуется использовать этот вид операции для номенклатуры находящиеся в резерве по заявке на МПЗ, поскольку могут повлиять на состояние заказов поставщику привязанный к заявке на МПЗ.
- Для отражения приходного ордера с видом операции «Излишки», пользователь должен в 1С.БИТ перейти в блок «Снабжение и склад», далее в разделе «Склад» выбрать «Приходный ордер» (Рисунок Г1).
Рисунок Г1. Открытие списка документов «Приходные ордера».
- Далее в открывшемся списке нажать на кнопку «Создать» (Рисунок Г2).
- Рисунок Г2. Создание документа «Приходный ордер».
- В открывшейся форме заполнить поля шапки документа (Рисунок Г3):
– Номер - присваивается программой автоматически.
– От (дата) - указать дату.
– Организация - обязательное поле заполняется из одноименного справочника.
– Вид операции - указать «Излишки».
- Склад - указать склад, на который будет сделано поступление излишек материалов.
– Инв. МПЗ – указать инвентаризационную опись, если излишки были оформлены в результате инвентаризации (поле не обязательно к заполнению).
- Рисунок Г3. Пример заполнения документа приходный ордер с видом операции «Излишки».
- Заполнить табличную часть «МПЗ» (Рисунок Г4).
Рисунок Г4. Заполнение табличной части МПЗ.
- Номенклатура – выбрать необходимую номенклатуру из справочника.
- Ед. изм. – подставится автоматически.
- К. – коэффициент – подставляется автоматически из номенклатуры, равен единице.
- Количество – заполнить количество (излишки).
- Цена – заполнить цену (если она известна).
- Сумма – заполнится автоматически.
- Сумма НДС – заполнить сумму НДС если необходимо.
- Всего – посчитается автоматически.
# 1.6 Приходный ордер с видом операции «Заправка»
Документ «Заправка (Приходный ордер)» предназначен для оформления факта заправки сторонней АЗС. Документ может быть создан в путевом листе на закладке «ГСМ» или непосредственно из журнала «Заправки» по кнопке [Создать]. Рассмотрим порядок заполнения документа из журнала «Заправки».
Для создания документа «Заправка» необходимо открыть раздел «АТ: Автотранспорт и строительная техника», далее в подразделе «ГСМ» найти документ «Заправка» (Рисунок Д1).
Рисунок Д1. Открытие документа заправка.
Откроется список документов «Заправки», где визуально окно (форму списка) можно разделить на три части, «Командная панель», «Область отборов документов в списке», «Список документов» (Рисунок Д2).

## 1.6.2 Заполнение табличной части МПЗ

- Сумма – заполнится автоматом.

Откроется форма присоединенные файлы, где через кнопку [Добавить] => [Файл с компьютера] вкладываем файл, находящийся на сетевом диске.

- Номер – присваивается программой автоматически.
- От (Дата) – указать дату фактического поступления на склад.
- Организация – выбрать организацию.
- Вид операции – указать «От поставщика».
- Контрагент – выбрать поставщика.
- Склад – выбрать склад, на который приходуется товар.
- Договор контрагента – выбрать договор поставщика.
- Бух. учет – установить признак.
- Заполнить табличную часть «МПЗ» (Рисунок Е4).
Рисунок Е4. Заполнение табличной части МПЗ.
- Номенклатура – выбрать необходимую номенклатуру из справочника.
- Ед. изм. – подставится автоматически.
- К. – коэффициент – подставляется автоматически из номенклатуры, равен единице.
- Количество – заполнить количество по накладной.
- Толеранс – данное поле заполняется автоматически если по факту поставлено больше, чем заказано, при условии, что документ «Приходный ордер» создается на основании заказа поставщику.
- Цена – заполнить цену по накладной.
- Сумма – заполнится автоматом.
- Сумма НДС – заполнить сумму НДС по накладной.
- Всего – посчитается автоматически.
- Для отражения признака давальческих материалов необходимо перейти во вкладку «Дополнительно» и установить галочку «Полученное давальческое сырье» (Рисунок Е5).
Рисунок Е5. Установка признака давальческого сырья.
Нажать на кнопку [Провести]. Документ сохранится. После проведения, необходимо напечатать форму М15.

- Рисунок Е6. Создание ПТУ на основании приходного ордера.
- Рисунок Е7. Сообщение об успешном создании УПД.
